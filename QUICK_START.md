# 🚀 YouTube Transcript Extractor - Quick Start

## ⚡ Instalação (1 minuto)

```bash
# Clone o repositório ou baixe os arquivos
pip install -r requirements-youtube.txt
```

## 📝 Extração da transcrição

```bash
# Seu vídeo
python youtube_transcript_extractor.py "https://youtu.be/UBFHTHUs1wA?is=Mqv4xij8F0D1jzeW"

# Salvar em arquivo
python youtube_transcript_extractor.py "https://youtu.be/UBFHTHUs1wA?is=Mqv4xij8F0D1jzeW" -o transcript.txt

# Salvar como JSON também
python youtube_transcript_extractor.py "https://youtu.be/UBFHTHUs1wA?is=Mqv4xij8F0D1jzeW" -o transcript.txt -j transcript.json
```

## 📂 Arquivos necessários

- `youtube_transcript_extractor.py` ✅
- `requirements-youtube.txt` ✅

Ambos estão no repositório pronto para usar!
