## 1. QUADRO RESUMIDO POR TIPO

### DIAMOND (Diamante)

```
┌─────────────────────────────────────────────────────┐
│ DIAMOND INTERCHANGE                                 │
├─────────────────────────────────────────────────────┤
│ Ramos:                    4 ramos (2 entrada, 2 saída) │
│ Aplicação:                Freeway × Arterial / Collector │
│ Volume via secundária:    5.000–15.000 veículos/dia │
│ Conversão à esquerda:     < 1.200 pcph              │
│ Sinalização via sec.:     OBRIGATÓRIA (semáforo)    │
│ Área exigida:             1,5–2,0 hectares          │
│ Custo (2025):             $15–25 M (baseline 100%)  │
│ Tempo de obra:            12–18 meses               │
│                                                       │
│ VELOCIDADES DE PROJETO                              │
│   • Via principal:        50–70 mph (80–115 km/h)  │
│   • Ramo (entrada/saída): 30–40 mph (50–65 km/h)   │
│   • Raio mínimo:          150–230 ft (46–70 m)     │
│   • Comprimento aceleração: 300–500 ft (90–150 m)  │
│   • Comprimento desaceleração: 250–400 ft (75–120 m)│
│                                                       │
│ VANTAGENS                                           │
│ ✓ Menor custo (baseline)                            │
│ ✓ Menor área exigida                                │
│ ✓ Construção rápida                                 │
│ ✓ Normas estabelecidas & consolidadas              │
│ ✓ Operação simples, manutenção baixa                │
│                                                       │
│ DESVANTAGENS                                        │
│ ✗ Requer sinalização semafórica (conflito residual)│
│ ✗ Capacidade limitada em volumes altos             │
│ ✗ Conversão à esquerda pode ter filas             │
│                                                       │
│ QUANDO USAR                                         │
│ • Freeway × via de menor classe (arterial, colector)│
│ • Volume baixo a médio                              │
│ • Área urbana com restrição de espaço              │
│ • Budgets limitados                                 │
│                                                       │
│ EXEMPLOS (Brasil)                                   │
│ • BR-116 × Via auxiliar (Rio, SP)                   │
│ • Acessos a shoppings em rodovias federais         │
└─────────────────────────────────────────────────────┘
```

### PARCLO — 2 Quadrantes (PARCLO A2/B2)

```
┌─────────────────────────────────────────────────────┐
│ TREVO PARCIAL — 2 QUADRANTES (PARCLO A2/B2)        │
├─────────────────────────────────────────────────────┤
│ Ramos:                    4 ramos (2 loops + 2 diretos)│
│ Configuração:             Um loop de entrada,        │
│                           um de saída (ou variante)  │
│ Aplicação:                Freeway × Arterial (crescimento)│
│ Volume via secundária:    10.000–20.000 veículos/dia│
│ Conversão à esquerda:     800–1.500 pcph            │
│ Sinalização via sec.:     PARCIAL (1–2 interseções) │
│ Área exigida:             3,0–4,0 hectares          │
│ Custo (2025):             $20–35 M (130–150%)       │
│ Tempo de obra:            18–24 meses               │
│                                                       │
│ VELOCIDADES DE PROJETO                              │
│   • Via principal:        50–70 mph (80–115 km/h)  │
│   • Loop (entrada/saída): 25–30 mph (40–48 km/h)   │
│   • Ramo direto:          30–35 mph (48–56 km/h)   │
│   • Raio loop:            150–200 ft (46–61 m)     │
│                                                       │
│ VANTAGENS                                           │
│ ✓ Custo moderado (melhor que Cloverleaf)            │
│ ✓ Fluxo livre via principal mantido                 │
│ ✓ Menos loops que Cloverleaf (maior velocidade)    │
│ ✓ Escalável (transição Diamond → Cloverleaf)        │
│ ✓ Adequado para crescimento urbano progressivo      │
│                                                       │
│ DESVANTAGENS                                        │
│ ✗ Mais caro que Diamond (30–50% adicional)         │
│ ✗ Ainda requer sinalização parcial na via sec.     │
│ ✗ Loops com raio crítico (segurança em curvas)     │
│ ✗ Entrecruzamento moderado em ramos                │
│                                                       │
│ QUANDO USAR                                         │
│ • Demanda crescente esperada                        │
│ • Transição do Diamond para capacidade maior        │
│ • Área intermediária disponível (3–4 ha)            │
│ • Volume conversão à esquerda 800–1.500 pcph       │
│                                                       │
│ QUANDO NÃO USAR                                     │
│ • Freeway × Freeway (sempre usar PARCLO 4Q)        │
│ • Volume < 5.000 veículos/dia (Diamond mais barato) │
│ • Freeway × Colector local (Diamond suficiente)    │
│                                                       │
│ VARIANTES (AASHTO)                                  │
│ • PARCLO A2: Loop para acesso (entrada)             │
│ • PARCLO B2: Loop para saída                        │
└─────────────────────────────────────────────────────┘
```

### PARCLO — 4 Quadrantes (PARCLO A4/B4)

```
┌─────────────────────────────────────────────────────┐
│ TREVO PARCIAL — 4 QUADRANTES (PARCLO A4/B4)        │
├─────────────────────────────────────────────────────┤
│ Ramos:                    6 ramos (2 loops + 4 diretos)│
│ Configuração:             Loops concentrados num lado│
│                           (norte ou sul)            │
│ Aplicação:                Freeway × Arterial (alt volume)│
│ Volume via secundária:    15.000–30.000 veículos/dia│
│ Conversão à esquerda:     1.200–2.000 pcph          │
│ Sinalização via sec.:     REDUZIDA (1 interseção)   │
│ Área exigida:             4,0–6,0 hectares          │
│ Custo (2025):             $25–50 M (170–200%)       │
│ Tempo de obra:            20–28 meses               │
│                                                       │
│ VELOCIDADES DE PROJETO                              │
│   • Via principal:        50–70 mph (80–115 km/h)  │
│   • Loop:                 25–35 mph (40–56 km/h)   │
│   • Ramo direto:          35–40 mph (56–65 km/h)   │
│   • Raio loop:            150–200 ft (46–61 m)     │
│                                                       │
│ VANTAGENS                                           │
│ ✓ Menor entrecruzamento que Cloverleaf completo     │
│ ✓ Loops concentrados = melhor operação              │
│ ✓ Múltiplos movimentos com fluxo livre              │
│ ✓ Transição segura (não tão abrupta quanto PARCLO 2Q)│
│ ✓ Custo moderado vs. capacidade oferecida           │
│                                                       │
│ DESVANTAGENS                                        │
│ ✗ Mais caro que PARCLO 2Q (70–100% adicional)      │
│ ✗ Maior consumo de área (4–6 ha)                    │
│ ✗ Loops ainda com limitações de velocidade          │
│ ✗ Projeto mais complexo que Diamond ou PARCLO 2Q   │
│                                                       │
│ QUANDO USAR                                         │
│ • Volume conversão à esquerda 1.200–2.000 pcph     │
│ • Demanda futura muito crescente                    │
│ • Evitar Cloverleaf completo por razões de espaço  │
│ • Freeway × Arterial principal urbana               │
│                                                       │
│ DIFERENÇA vs. 2 QUADRANTES                          │
│ • Loops em MESMO lado (norte OU sul)                │
│ • Ramos diretos no lado oposto                      │
│ • Menos conflito que Cloverleaf (loops não ocupam   │
│   todos os 4 quadrantes)                            │
│ • Sinalização semafórica apenas em UMA interseção   │
│   (não duas como em PARCLO 2Q)                      │
└─────────────────────────────────────────────────────┘
```

### TREVO COMPLETO (CLOVERLEAF / Full Cloverleaf)

```
┌─────────────────────────────────────────────────────┐
│ TREVO COMPLETO (CLOVERLEAF / FULL CLOVERLEAF)      │
├─────────────────────────────────────────────────────┤
│ Ramos:                    8 ramos (4 loops + 4 diretos)│
│ Aplicação:                Formalmente DESACONSELHADO │
│                           (AASHTO 1990+)             │
│ Volume via secundária:    25.000–40.000 veículos/dia│
│ Conversão à esquerda:     > 2.000 pcph              │
│ Sinalização via sec.:     NENHUMA (fluxo contínuo)  │
│ Área exigida:             6,0–10,0+ hectares        │
│ Custo (2025):             $30–60 M (200–250%)       │
│ Tempo de obra:            24–36 meses               │
│ Descontinuações:          10–15% todos os projetos 2023–2026 │
│                                                       │
│ VELOCIDADES DE PROJETO                              │
│   • Via principal:        50–70 mph (80–115 km/h)  │
│   • Loop:                 20–25 mph (32–40 km/h) ← CRÍTICO│
│   • Raio loop (mín.):     100–150 ft (30–46 m) ← MUITO CURTO│
│                                                       │
│ PROBLEMAS CONHECIDOS                                │
│ ✗ Entrecruzamento severo (weaving) → acidentes      │
│ ✗ Raio de loop muito pequeno (20–25 mph)            │
│ ✗ Visibilidade reduzida nas curvas                  │
│ ✗ Circulação simultânea em múltiplos acessos        │
│ ✗ Alto custo de OAE (4 viadutos)                    │
│ ✗ Manutenção cara (estruturas complexas)            │
│                                                       │
│ DESVANTAGENS                                        │
│ ✗ Desaconselhado AASHTO desde ~1990                 │
│ ✗ Custo 200–250% vs. Diamond                        │
│ ✗ Área grande exigida (6–10+ ha)                    │
│ ✗ Acidentes em entrecruzamento                      │
│ ✗ Operações complexas (fluxo + weaving)             │
│                                                       │
│ VANTAGENS (HISTÓRICAS)                              │
│ ✓ Zero sinalização via secundária                   │
│ ✓ Fluxo contínuo em baixas velocidades              │
│ ✓ (Essas vantagens obsoletas — PARCLO oferece!)     │
│                                                       │
│ STATUS ATUAL (2026)                                 │
│ • Raro em projetos novos (EUA, Brasil)              │
│ • Redesenho comum em concessões/PPP                 │
│ • Exemplos remanescentes:                           │
│   - I-35/I-40 (Oklahoma) — em modernização          │
│   - Marginais São Paulo — desenhos dos anos 1980    │
│   - Algumas rodovias federais Brasil                │
│                                                       │
│ QUANDO USAR (MUITO EXCEPCIONAL)                     │
│ • SOMENTE se volume > 30.000 veículos/dia           │
│ • SOMENTE se Freeway × Freeway (não Arterial)       │
│ • SOMENTE se Directional não viável economicamente  │
│ • Terreno rural com custo OAE muito baixo           │
│ → Recomendação: Preferir PARCLO 4Q (100% dos casos)│
│                                                       │
│ TENDÊNCIA                                           │
│ ⚠️  Descontinuação gradual esperada em 2030–2035   │
│    Modernizações substituem por PARCLO ou Directional│
└─────────────────────────────────────────────────────┘
```

### DIRECIONAL & SEMIDIRECIONAL

```
┌─────────────────────────────────────────────────────┐
│ DIRECIONAL & SEMIDIRECIONAL                         │
├─────────────────────────────────────────────────────┤
│ Ramos:                    4–6 ramos direcionais      │
│ Aplicação:                SOMENTE Freeway × Freeway │
│ Volume pista principal:   > 50.000 veículos/dia     │
│ Volume pista secundária:  > 40.000 veículos/dia     │
│ Conversão à esquerda:     > 3.000 pcph              │
│ Sinalização:              NENHUMA (fluxo livre)     │
│ Níveis de greide:         3–4 (múltiplos viadutos)  │
│ Área exigida:             10,0–20,0+ hectares       │
│ Custo (2025):             $80–300 M (400–1.200%)!!! │
│ Tempo de obra:            36–60+ meses              │
│ Exemplos mundiais:        Raros (3–4 por país)     │
│                                                       │
│ VELOCIDADES DE PROJETO                              │
│   • Via principal:        65–75 mph (105–120 km/h) │
│   • Ramo direcional:      40–50 mph (65–80 km/h) ← O DIFERENCIAL│
│   • Raio direto:          200–300 ft (61–91 m) ← CRÍTICO │
│   • Comprimento aceleração: 400–700 ft (120–210 m) │
│   • Comprimento desaceleração: 350–600 ft (105–180 m)│
│                                                       │
│ DIRECIONAL TOTAL (FULLY DIRECTIONAL)                │
│ • Todos os 4 movimentos principal com ramos diretos │
│ • Sem loops                                          │
│ • 3–4 níveis de greide                              │
│ • Custo MÁXIMO (600–1.200% do Diamond)              │
│                                                       │
│ SEMIDIRECIONAL                                      │
│ • 2–3 movimentos diretos, 1–2 com loops/ramos curtos│
│ • 2–3 níveis de greide (mais economizado)           │
│ • Custo moderado (400–600% do Diamond)              │
│                                                       │
│ VANTAGENS                                           │
│ ✓ Fluxo livre em conversão à esquerda crítica       │
│ ✓ Velocidades operacionais altas (40–50 mph ramos) │
│ ✓ Segurança máxima (sem sinais, sem conflitos)     │
│ ✓ Capacidade máxima (> 100.000 VMD total)          │
│ ✓ Redundância em caso de incidente (múltiplas vias) │
│                                                       │
│ DESVANTAGENS                                        │
│ ✗ Custo PROIBITIVO (400–600% Diamond)              │
│ ✗ OAE complexas (múltiplos viadutos)                │
│ ✗ Construção muito longa (36–60 meses)             │
│ ✗ Operação & manutenção cara                        │
│ ✗ Impacto ambiental (área grande)                  │
│ ✗ Raramente justificado economicamente              │
│                                                       │
│ QUANDO USAR                                         │
│ • SOMENTE Freeway × Freeway (não Arterial)         │
│ • Volume AMBAS pistas > 80.000 VMD                  │
│ • Conversão à esquerda > 3.000 pcph                 │
│ • Recursos orçamentários sem restrição             │
│ • Benefício social claro (redução acidentes crítica)│
│                                                       │
│ EXEMPLOS (2025)                                     │
│ Brasil:                                             │
│ • Marginal Pinheiros × Imigrantes (São Paulo)      │
│ • Rodoanel Mário Covas × Marginal (SP)             │
│                                                       │
│ EUA:                                                │
│ • I-95 / I-495 (Capital Beltway, DC)               │
│ • I-405 / I-10 (Los Angeles, Califórnia)           │
│ • I-37 / I-69 (Texas)                               │
│                                                       │
│ FUTURO                                              │
│ • Evolução para SPUI (Single Point Urban)          │
│   com sinal semafórico = custo reduzido           │
│ • Automação (conectados, V2X) pode melhorar         │
│   operação sem custo estrutural adicional           │
└─────────────────────────────────────────────────────┘
```

## 2. MATRIZ DE SELEÇÃO RÁPIDA

### Árvore de Decisão

```
┌─────────────────────────────────────────────┐
│       QUAL TIPO DE INTERCONEXÃO ESCOLHER?   │
├─────────────────────────────────────────────┤
│                                             │
│ [1] É Freeway × Freeway?                   │
│     ├─ SIM → Volume TOTAL > 80k VMD?       │
│     │   ├─ SIM → DIRECTIONAL ou SPUI       │
│     │   └─ NÃO → PARCLO 4Q                 │
│     │                                       │
│     └─ NÃO → É Freeway × Arterial?        │
│         ├─ SIM → Volume Arterial?          │
│         │   ├─ 5–15k → DIAMOND              │
│         │   ├─ 15–30k → PARCLO 2Q ou 4Q    │
│         │   └─ > 30k → PARCLO 4Q           │
│         │                                   │
│         └─ NÃO → Arterial × Arterial      │
│             └─ Use interseção em nível    │
│                (rótula ou sinal)           │
│                                             │
│ [2] Verificar Conversão à Esquerda (pcph)  │
│     ├─ < 1.200 → DIAMOND                   │
│     ├─ 1.200–2.000 → PARCLO (2Q ou 4Q)     │
│     └─ > 2.000 → Cloverleaf (NÃO!) ou      │
│               → DIRECTIONAL (se F×F)       │
│                                             │
│ [3] Verificar Área Disponível (hectares)   │
│     ├─ < 2 → DIAMOND OBRIGATÓRIO           │
│     ├─ 2–4 → DIAMOND ou PARCLO 2Q          │
│     ├─ 4–8 → PARCLO 2Q ou 4Q               │
│     └─ > 8 → PARCLO 4Q ou DIRECTIONAL      │
│                                             │
│ [4] Verificar Orçamento (vs. baseline)    │
│     ├─ Apertado (< 20 M USD) → DIAMOND     │
│     ├─ Moderado (20–50 M) → PARCLO         │
│     ├─ Robusto (50–100 M) → PARCLO 4Q      │
│     └─ Sem limite (> 100 M) → DIRECTIONAL  │
│                                             │
│ [5] Verificar Cronograma                   │
│     ├─ Rápido (< 18 meses) → DIAMOND       │
│     ├─ 18–24 meses → PARCLO 2Q             │
│     ├─ 24–36 meses → PARCLO 4Q             │
│     └─ 36+ meses → DIRECTIONAL             │
│                                             │
└─────────────────────────────────────────────┘
```

## 5. CHECKLIST DE PROJETO

### Antes de iniciar o projeto conceitual:

- [ ] **Coletar dados:**
  - [ ] VMD ano atual (todos os movimentos)
  - [ ] Projeção VMD (10º, 20º ano)
  - [ ] VHP (pico-hora) conversão à esquerda
  - [ ] Classe funcional (DNIT/AASHTO)
  - [ ] Velocidade de projeto via principal & secundária
  - [ ] Terreno & topografia (mapa altimétrico)
  - [ ] Tipo de solo (sondagem)
  - [ ] Cadastro de utilities (hidráulico, elétrico, gás)

- [ ] **Análise de critérios:**
  - [ ] Volume via secundária → tipo inicial (Diamond/PARCLO)
  - [ ] Conversão à esquerda → verificar se requer sinalização
  - [ ] Disponibilidade de área → confirmar viabilidade
  - [ ] Orçamento preliminar → compatibilidade

- [ ] **Revisão normativa:**
  - [ ] DNIT IPR-718 (Brasil)
  - [ ] AASHTO Green Book (internacional)
  - [ ] Manual estadual de projeto (se aplicável)
  - [ ] CONTRAN (sinalização, Brasil)
  - [ ] NBRs (carga móvel, OAE, pavimentação)

- [ ] **Consultas prévias:**
  - [ ] DNIT/órgão concedente (alinhamento normativo)
  - [ ] Ambientais (necessidade de licença prévia)
  - [ ] Concessionária de utilities (relocações)

## 7. NOTAS FINAIS

✓ **Diamond é o "default"** — usar sempre que volume permitir  
✓ **PARCLO = escalabilidade** — sem salto dramático de custo  
✗ **Cloverleaf está obsoleto** — evitar em novos projetos  
✓ **Directional = raridade** — apenas megacidades, volumes extremos  

**Recomendação de Projeto (Workflow):**

1. **Estude com Diamond** (custo baseline, normas consolidadas)
2. **Se volume > 1.200 pcph (conv. esq.),** escale para PARCLO 2Q
3. **Se volume > 2.000 pcph,** use PARCLO 4Q
4. **Directional somente após análise econômica explícita** (custo 5–10× maior)
5. **Sempre consulte** DNIT/AASHTO + órgão regulador
