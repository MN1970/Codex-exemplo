## 1. PANORAMA DE NORMAS INTERNACIONAIS

### 1.1 AASHTO (American Association of State Highway Officials)

**Referência Primária:** *A Policy on Geometric Design of Highways and Streets* (Green Book), 6ª Edição  
**Escopo:** Padrão de fato para design geométrico de rodovias e ruas em América do Norte e referência global

#### Critérios AASHTO para Interconexões:

| Critério | Aplicação | Especificação |
|----------|-----------|---------------|
| **Classe da Via** | Determina padrão mínimo | Freeway, Arterial, Collector, Local |
| **Velocidade de Projeto** | Governa raios e comprimentos | 30 mph (loop mín.) até 70+ mph (rodovia) |
| **Volume (VMD)** | Define necessidade de desnível | Hierarquia: Diamond < Partial Cloverleaf < Cloverleaf < Directional |
| **Espaçamento entre Interconexões** | Distância mínima | **Urban:** 1 km (0,6 mi); **Rural:** 3,2 km (2 mi) |

---

### 1.2 PIANC (Permanent International Association of Navigation Congresses)

**Escopo Primário:** Design de portos, terminais marinhos e acesso rodoviário a terminais multimodais

#### Aplicação em Interconexões Rodoviárias Portuárias:

| Aspecto | Recomendação PIANC | Nota |
|--------|-------------------|------|
| **Acesso Rodoviário a Terminais** | Vias de fluxo livre (Diamond/Directional) | Interconexão deve acomodar movimento de contêiner, veículos pesados |
| **Raio Mínimo Curva** | 60–80 m (função do veículo-tipo) | Caminhão articulado (16,5 m) requer curva de transição |
| **Integração Multimodal** | Separação modal com ciclovias e passarelas | Comum em terminais portuários modernos |
| **Ciclos de Fila (Queue Storage)** | Armazenagem mínima = 2 minutos de pico | Evita congestionamento na via principal |

**Nota:** PIANC NÃO estabelece norma própria para interconexões rodoviárias; refere-se a AASHTO e BS 6349 (UK). Foco principal é integração com terminal de carga e operação portuária.

---

### 1.3 ICAO (International Civil Aviation Organization)

**Escopo Primário:** Aviação civil — Annex 14 (Aerodromes)

**Aplicação Limitada a Interconexões Rodoviárias:**
- **ICAO NÃO regulamenta** interconexões rodoviárias tipo diamond/cloverleaf
- **Aplicável apenas:** Acesso rodoviário a aeroportos
  - Via de acesso a aeroporto deve estar **fora da zona de proteção de aproximação** (safeguard zones)
  - **Velocidade de projeto mínima:** 80–100 km/h (50–60 mph) para vias de acesso
  - **Raio mínimo:** 150–200 m (função de veículo-tipo)

**Conclusão:** ICAO remete a normas nacionais (AASHTO, DNIT) para projeto geométrico da interconexão.

## 2. HIERARQUIA DE TIPOS DE INTERCONEXÃO

### Classificação por Capacidade & Custo (AASHTO)

```
CAPACIDADE & CUSTO CRESCENTE →

Diamond
    ↓ (capacidade +15%)
Partial Cloverleaf (2 quad.)
    ↓ (capacidade +20%)
Partial Cloverleaf (4 quad. / PARCLO)
    ↓ (capacidade +30%)
Full Cloverleaf (4 loops)
    ↓ (capacidade +25%, custo alto por OAE)
Directional / Semidirecional
    ↓ (custo máximo, volumes extremos)
```

## 3. CRITÉRIOS DE SELEÇÃO POR TIPO

### 3.1 DIAMOND (Diamante)

**Quando usar:**
- Freeway × Arterial ou Collector (não freeway × freeway)
- VMD da via secundária < 5.000 veículos/dia
- Conversões à esquerda < 1.200 pcph (passenger car per hour)
- Disponibilidade de área: **pequena** (1,5–2 ha típico)
- Urbano ou rural, ambos aplicáveis

**Critérios de Seleção (AASHTO):**

| Parâmetro | Critério |
|-----------|----------|
| **Vol. intersecção (via secundária)** | 5.000–15.000 veículos/dia |
| **Conversão esq. (pico-hora)** | < 1.200 pcph |
| **Sinalização na via secundária** | **Obrigatória** (semáforo ou rótula) |
| **Fluxo livre via principal** | Sim — via passa sob/sobre secundária |
| **Velocidade projeto ramo** | 30–40 mph (50–65 km/h) |
| **Área mínima** | ~1,5–2,0 hectares |

**Velocidades de Projeto:**

| Elemento | Design Speed |
|----------|--------------|
| Via principal | 50–70 mph (80–115 km/h) |
| Ramo (saída/entrada) | 30–40 mph (50–65 km/h) |
| Raio mínimo ramo | 150–230 ft (46–70 m) |
| Comprimento aceleração | 300–500 ft (90–150 m) |
| Comprimento desaceleração | 250–400 ft (75–120 m) |

**Custo Relativo:** **Baseline (100%)**

---

### 3.2 TREVO PARCIAL — 2 Quadrantes (PARCLO A2/B2)

**Quando usar:**
- Freeway × Arterial, mas com restrição de área
- VMD secundária: 10.000–20.000 veículos/dia
- Conversões à esquerda: 800–1.500 pcph
- Disponibilidade de área: **média** (3–4 ha)
- Rural com demanda crescente

**Critérios de Seleção:**

| Parâmetro | Critério |
|-----------|----------|
| **Vol. intersecção via secundária** | 10.000–20.000 veículos/dia |
| **Conversão esq. (pico-hora)** | 800–1.500 pcph |
| **Loops** | 2 (entrada + saída, ou variante) |
| **Sinalização via secundária** | **Parcial** (uma ou duas interseções) |
| **Fluxo livre via principal** | Sim |
| **Velocidade projeto ramos** | 25–35 mph (40–56 km/h) |
| **Área mínima** | ~3,0–4,0 hectares |

**Velocidades de Projeto:**

| Elemento | Design Speed |
|----------|--------------|
| Via principal | 50–70 mph (80–115 km/h) |
| Loop (entrada/saída) | 25–30 mph (40–48 km/h) |
| Raio loop | 150–200 ft (46–61 m) |
| Ramos diretos | 30–35 mph (48–56 km/h) |

**Custo Relativo:** **130–150% do Diamond** (ainda economicamente viável vs. Cloverleaf)

---

### 3.3 TREVO PARCIAL — 4 Quadrantes (PARCLO A4/B4)

**Quando usar:**
- Demanda crescente, transição Diamond → Cloverleaf
- VMD secundária: 15.000–30.000 veículos/dia
- Conversões à esquerda: 1.200–2.000 pcph
- Loops em mesmo lado (reduz entrecruzamento)
- Disponibilidade de área: **média-grande** (4–6 ha)

**Critérios de Seleção:**

| Parâmetro | Critério |
|-----------|----------|
| **Vol. intersecção via secundária** | 15.000–30.000 veículos/dia |
| **Conversão esq. (pico-hora)** | 1.200–2.000 pcph |
| **Loops** | 2 (mesmo lado da rodovia) |
| **Ramos diretos** | 4 (lados opostos) |
| **Sinalização via secundária** | **Reduzida** (uma interseção) |
| **Fluxo livre via principal** | Sim, para múltiplos movimentos |
| **Velocidade projeto** | 25–35 mph loops; 35–40 mph diretos |
| **Área mínima** | ~4,0–6,0 hectares |

**Custo Relativo:** **170–200% do Diamond**

---

### 3.4 TREVO COMPLETO (CLOVERLEAF)

**Quando usar:**
- Freeway × Freeway, **formalmente não recomendado**
- Freeway × Arterial com **altíssimo volume** (>30.000 veículos/dia)
- **Movimentos de conversão à esquerda CRÍTICOS** (>2.000 pcph)
- Área disponível: **grande** (6–10 ha ou mais)
- Terreno favorável (baixo custo OAE)
- Rural, longe de centros urbanos (custo terra menor)

**Critérios de Seleção:**

| Parâmetro | Critério |
|-----------|----------|
| **Vol. intersecção via secundária** | 25.000–40.000 veículos/dia |
| **Conversão esq. (pico-hora)** | **> 2.000 pcph** |
| **Loops** | 4 (todos os quadrantes) |
| **Sinalização via secundária** | **Nenhuma** — fluxo contínuo |
| **Fluxo livre via principal** | Sim |
| **Velocidade projeto loops** | 20–25 mph (32–40 km/h) |
| **Raio loop** | 100–150 ft (30–46 m) — mínimo crítico |
| **Área mínima** | **6,0–10,0+ hectares** |

**Problemas Conhecidos (AASHTO):**
1. **Entrecruzamento (weaving)** entre loop e ramos diretos causa acidentes
2. **Circulação no anel** com múltiplos acessos simultâneos = congestionamento
3. **Visibilidade reduzida** em loops (curva de pequeno raio)
4. **Não recomendado para freeway-to-freeway** há 30+ anos

**Custo Relativo:** **200–250% do Diamond**

**Status Atual (2026):** Raramente aprovado em novos projetos; redesenho comum em projetos de modernização.

---

### 3.5 DIRECIONAL & SEMIDIRECIONAL

**Quando usar:**
- **Somente freeway × freeway** (autoestrada × autoestrada)
- Conversão à esquerda: **> 3.000 pcph** ou mais
- Volumes totais: **> 100.000 VMD** (ambas as pistas)
- Área disponível: **muito grande** (10–20+ ha)
- Velocidades de projeto altas (65–75 mph nas ramps)
- **Recursos financeiros significativos** (obra pesada OAE/viadutos)

**Critérios de Seleção:**

| Parâmetro | Critério |
|-----------|----------|
| **Vol. pista principal** | > 50.000 veículos/dia |
| **Vol. pista secundária** | > 40.000 veículos/dia |
| **Conversão esq. (pico-hora)** | **> 3.000 pcph** ou mais |
| **Ramos direcionais** | 2–4 (cada conversão crítica) |
| **Sinalização** | **Nenhuma** — fluxo livre contínuo |
| **Níveis de greide** | **3–4** (múltiplos viadutos) |
| **Velocidade projeto ramos** | **40–50 mph (65–80 km/h)** — o diferencial |
| **Raio mínimo ramos** | 200–300 ft (61–91 m) |
| **Área mínima** | **10,0–20,0+ hectares** |

**Velocidades de Projeto Comparadas:**

| Tipo | Loop/Ramo Curto | Ramo Direcional |
|------|-----------------|-----------------|
| Cloverleaf | 20–25 mph | — |
| PARCLO | 25–30 mph | — |
| Diamond | 30–40 mph | — |
| **Directional** | — | **40–50 mph** |

**Custo Relativo:** **400–600% do Diamond** (pode chegar a 800% em áreas urbanas com OAE complexas)

**Exemplos:** Interconexões I-95/I-495 (DC beltway), I-405/I-10 (Los Angeles), São Paulo (Marginal Pinheiros × Imigrantes)

### 4.2 Custo Absoluto (Estimativas 2025–2026, EUA)

**Nota:** Valores em USD, variáveis conforme região, terreno, quantidade OAE

| Tipo | Faixa Típica | Por Unidade |
|------|------|-----------|
| **Diamond** | $15–25 M | 100% |
| **PARCLO 2Q** | $20–35 M | 130–140% |
| **PARCLO 4Q** | $25–50 M | 170–200% |
| **Cloverleaf** | $30–60 M | 200–240% |
| **Semidirecional** | $80–150 M | 400–600% |
| **Totalmente Direcional** | $150–300+ M | 600–1.200% |

**Fatores de Multiplicação:**
- **OAE (viadutos/passarelas):** +50–100% por estrutura
- **Terreno urbano vs. rural:** 2–3× multiplicador
- **Rocha escavação:** +20–40% vs. terra
- **Desvio de tráfego durante obra:** +15–30% adicional

**Exemplos Recentes (2023–2026):**
- **Diamond (I-37, Texas):** $18 M, 18 meses
- **PARCLO (I-81, Virginia):** $42 M, 24 meses
- **Semidirecional (DC-Beltway, renovation):** $200+ M, 36+ meses

## 6. CRITÉRIOS DE ENQUADRAMENTO NORMATIVO

### 6.1 Matriz de Decisão (AASHTO + DNIT adaptado)

```
INÍCIO
  ↓
[1] Qual é o tipo de cruzamento?
  ├─ Freeway × Freeway?
  │   ├─ Sim → PARCLO mínimo; considerar Direcional se vol. > 80k/dia
  │   └─ Não → Prossiga
  │
  ├─ Freeway × Arterial?
  │   ├─ Sim → Prossiga para [2]
  │   └─ Não → Considerar interseção em nível
  │
  └─ Arterial × Arterial?
      └─ Considerar Diamond ou nível, conforme volume
  
  ↓
[2] Qual é o volume da via secundária (10º ano)?
  ├─ < 5.000 veículos/dia → Diamond (custo mínimo)
  ├─ 5–15k → Diamond ou PARCLO 2Q (transição)
  ├─ 15–30k → PARCLO 2Q ou PARCLO 4Q
  ├─ 30–40k → PARCLO 4Q (evitar Cloverleaf)
  └─ > 40k → Cloverleaf ou Directional (apenas se Freeway)
  
  ↓
[3] Conversão à esquerda (pico-hora)?
  ├─ < 1.000 pcph → Tipo econômico (Diamond/PARCLO 2Q)
  ├─ 1.000–2.000 → PARCLO 4Q
  ├─ 2.000–3.000 → Considerar Cloverleaf (obsoleto)
  └─ > 3.000 → Directional (se Freeway × Freeway)
  
  ↓
[4] Área disponível (ha)?
  ├─ < 2 → **Diamond obrigatório**
  ├─ 2–4 → PARCLO 2Q
  ├─ 4–8 → PARCLO 4Q ou Cloverleaf
  └─ > 8 → Directional factível
  
  ↓
[5] Velocidade de projeto da rodovia?
  ├─ < 50 mph → Não recomenda Directional
  └─ > 65 mph → Directional preferível se volumes justificarem
```

## 7. CRITÉRIOS ESPECÍFICOS BRASIL (DNIT IPR-718 + AASHTO)

### 7.1 Aplicação no Contexto Brasileiro

O DNIT IPR-718 (2005) referencia AASHTO com adaptações:

| Critério | AASHTO | DNIT | Nota |
|----------|--------|------|------|
| **Velocidade projeto via principal** | 50–75 mph | 80–120 km/h | DNIT = 50–75 km/h típico |
| **Raio mínimo ramo** | 150–300 ft | 45–91 m | Equivalente |
| **Volume critério** | VMD (10º ano) | VMD (10º ano) | Mesma base |
| **Superelevação máx.** | 8–12% | 10% | DNIT mais conservador |
| **Sinalização** | Manual MUTCD | Manual Brasileiro CONTRAN | Cores idênticas |

### 7.2 Classificação DNIT de Rodovias

| Classe DNIT | Equivalente EUA | Velocidade Projeto | Tipo Interconexão Típico |
|------------|-----------------|-------------------|--------------------------|
| **Classe 0** | Freeway | 100–120 km/h | Diamond, PARCLO |
| **Classe I-A** | Freeway | 100 km/h | Diamond, PARCLO |
| **Classe I-B** | Arterial Principal | 80 km/h | Diamond |
| **Classe II** | Arterial Menor | 60 km/h | Diamond ou nível |
| **Classe III** | Collector | 40 km/h | Nível (rótula típica) |

### Para cada projeto de interconexão, verificar:

**✓ Dados Básicos**
- [ ] Classe funcional das duas vias (DNIT/AASHTO)
- [ ] Volume 10º ano (VMD) para cada via
- [ ] Volume pico-hora (VHP) conversão à esquerda
- [ ] Velocidade de projeto (mainline e ramos)

**✓ Normas Aplicáveis**

- [ ] Manuais estaduais/federais (se aplicável)

## 10. NOTAS FINAIS & CONCLUSÕES

### Status da Tecnologia de Interconexões (2026)

1. **Diamond segue dominante** em projetos novos EUA & Brasil por:
   - Menor custo (20–25 M USD típico)
   - Menor área exigida (1,5–2 ha)
   - Bem-testado, normas maduras

2. **PARCLO em crescimento** para freeway-to-arterial com demanda crescente

3. **Cloverleaf em declínio:**
   - Formalmente desaconselhado AASHTO desde 1990
   - Entrecruzamento causa acidentes
   - Redesenho comum em rodovias concedidas (SP, RJ, MG)

4. **Directional raro fora de megacidades:**
   - Custo proibitivo (400–600% do Diamond)
   - Apenas 3–4 exemplares operacionais Brasil
   - Futuro: possível em SPUI (Single Point Urban Interchange) com controle semafórico

5. **ICAO e PIANC NÃO regulamentam** interconexões de rodovias standard:
   - PIANC fornece interface com terminais (áreas de espera, raios de curva)
   - ICAO remete a AASHTO para acesso a aeroportos

### Recomendação para Novos Projetos

**Prioridade 1:** Dimensionar sempre com Diamond como baseline  
**Prioridade 2:** Avaliar PARCLO se vol. conversão > 1.200 pcph
