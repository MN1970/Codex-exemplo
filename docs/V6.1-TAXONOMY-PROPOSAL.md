| Eixo | Repo v4.9 | SP v5.1 | Divergências |
|---|---|---|---|
| **S** (segmentos) | S1-S13 (13 verticais) | S1-S11 (11 verticais) | S5, S6 renumerados; S12/S13 (Óleo&Gás, Edificações) não existem no SP; Túneis/Mineração/Óleo&Gás/Edificações não existem lá |

| **F** (funcionais) | F1-F9 (9) + F2 SP fallback | F1-F10 (10) | SP tem F10-pesquisa-evolutiva que não existe no repo |

Impacto operacional: routing quebrado (SKILL v1.1.0 aponta para pasta que não
existe), reconciliação `sp_operational_segment` desatualizada, códigos `Manta
03-S{n}` no repo não batem com códigos `S{n}` no SP.
