## 3. TABELA DE DECISÃO RÁPIDA — QUAL DISPOSITIVO USAR?

### Tabela 3.1: Árvore de Decisão (Passo a Passo)

```
┌─────────────────────────────────────────────────────────────┐
│ DECISÃO 1: QUAL É A VELOCIDADE DE PROJETO (VP)?            │
└─────────────────────────────────────────────────────────────┘

VP ≤ 60 km/h  →  DECISÃO 2
├─ Área livre ≥ 4,5 m?
│  ├─ SIM  → Defensa metálica simples (e = 3,00 m) — DNIT Manual
│  └─ NÃO  → Barreira rígida (h = 0,81 m) — DNIT IPR-718
└─ Há obstáculo fixo próximo?
   └─ SIM (< 1,0 m) → Atenuador localizado — DNIT Manual

60 < VP ≤ 80 km/h  →  DECISÃO 3
├─ Área livre ≥ 6,0 m?
│  ├─ SIM  → Defensa dupla (2 trilhos paralelos) — DNIT Manual
│  └─ NÃO  → Barreira rígida — DNIT IPR-718
└─ Há pilar de OAE?
   └─ SIM → Atenuador + Barreira rígida — DNIT Manual

80 < VP ≤ 100 km/h  →  DECISÃO 4
├─ Área livre ≥ 7,5 m?
│  ├─ SIM  → Defensa dupla + Atenuador em crítico — DNIT Manual
│  └─ NÃO  → Barreira rígida dupla ou com atenuador — DNIT Manual
└─ Ambiente (rodovia/viaduto)?
   ├─ Rodovia → Defensa dupla (ambos lados)
   └─ Viaduto → Barreira rígida (economia de espaço)

VP > 100 km/h  →  DECISÃO 5
└─ Sempre: Barreira rígida + Atenuador — DNIT Manual + ANTT

┌─────────────────────────────────────────────────────────────┐
│ DECISÃO 2: QUAL É O TIPO DE TALUD/OBSTÁCULO?               │
└─────────────────────────────────────────────────────────────┘

Talude de corte (altura > 3 m)
├─ Com área livre 4,5–6,0 m → Defensa metálica simples
└─ Com área livre < 3,0 m   → Barreira rígida

Talude de aterro (altura > 2 m)
├─ Inclinação 1V:2H         → Defensa simples suficiente
└─ Inclinação 1V:1H         → Defensa dupla ou barreira

Canteiro central
├─ Largura 1,0–1,5 m        → Barreira rígida obrigatória
└─ Largura > 2,0 m          → Defensa simples ou anti-ofuscante

Pilar de viaduto ou OAE
├─ Distância à pista > 2,0 m → Defensa metálica
├─ Distância à pista 1,5–2,0 m → Atenuador + Defensa
└─ Distância à pista < 1,5 m → Atenuador + Barreira rígida

┌─────────────────────────────────────────────────────────────┐
│ DECISÃO 3: QUAL É O TIPO DE INTERSEÇÃO?                    │
└─────────────────────────────────────────────────────────────┘

Em Nível (DNIT IPR-718 Cap. 8)
├─ Interseção T/Y      → Defensa em talud de acesso; demarcação 
│                         CONTRAN branca/amarela
├─ Rótula              → Defensa em acesso circular; balizadores 
│                         em aproximação
└─ Critério: Sinalização semafórica > 2 acessos

Desnível (DNIT IPR-718 Cap. 7)
├─ Diamante (4 ramos)  → Defensa em saída/entrada; atenuador no 
│                         nariz
├─ Trevo (8 ramos)     → Atenuador + Barreira rígida em loops; 
│                         defensa em bordo
├─ Trevo Parcial (4-6 ramos) → Defensa dupla + atenuador em 
│                               bifurcação
└─ Trombeta (3 ramos)  → Atenuador no laço de conversão

┌─────────────────────────────────────────────────────────────┐
│ DECISÃO 4: QUAL É A FREQUÊNCIA DE TRÁFEGO/ACIDENTES?       │
└─────────────────────────────────────────────────────────────┘

Rodovia de alto volume (VMD > 20.000 veículos/dia)
├─ Com histórico de acidentes → Barreira rígida + Atenuador
└─ Sem acidentes recentes    → Defensa dupla (revisão anual)

Rodovia de médio volume (10.000–20.000 veículos/dia)
├─ Trecho montanhoso (muitas curvas) → Defensa dupla
└─ Trecho plano                      → Defensa simples

Rodovia de baixo volume (< 10.000 veículos/dia)
├─ Acesso rural            → Defensa simples (se houver)
└─ Via de menor circulação → Sinalização (sem defensa obrigatória)

┌─────────────────────────────────────────────────────────────┐
│ DECISÃO 5: QUAL É O REGIME DE MANUTENÇÃO?                 │
└─────────────────────────────────────────────────────────────┘

Rodovia Federalizada (DNIT)
├─ Periodicidade de inspeção: Semestral (DNIT Manual)
├─ Reparos: Em até 30 dias (ANTT se concedida)
└─ Custo: Orçado anualmente

Rodovia Concedida (ANTT)
├─ Periodicidade de inspeção: Trimestral (época chuvosa), semestral (seca)
├─ Cronograma: Conforme Programa de Exploração (PER)
├─ Reparos: Em até 7 dias após notificação
└─ Cobrança: Multa + custo de reparo à concessionária

Rodovia Municipal
├─ Periodicidade: Conforme orçamento municipal
├─ Norma referência: CONTRAN + DNIT (esforço adaptado)
└─ Custo: Limitado; priorizar defensas metálicas em taludes críticos
```
