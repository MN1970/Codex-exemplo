## 1. INTRODUÇÃO

### 1.1 Escopo

O **PGA Calculator** (D6.1) é um módulo computacional para:
- Estimar a **Aceleração Máxima do Solo (PGA)** em um local específico a partir de coordenadas geográficas
- Determinar a **Classe de Sítio NEHRP** (A–F) baseado em velocidade média de onda de cisalhamento (Vs30)
- Calcular fatores de amplificação **Fa** (curto período) e **Fv** (períodos longos) conforme NEHRP 2020
- Gerar o **espectro de resposta Sa(T)** (aceleração espectral) em função do período fundamental
- Fornecer dados de entrada a cálculos de demanda sísmica para estruturas em OAE, ferrovias, metrô e pontes

### 1.2 Motivação

Projetos de infraestrutura em zonas sísmicas (Brasil, Sudeste/Nordeste, com risco sísmico variável) exigem avaliação de hazard sísmico. O módulo D6.1 integra:
- **USGS Earthquake Hazards Program** (API de dados sísmicos mapeados globalmente)
- **Padrão NEHRP 2020** (seleção de fatores Fa, Fv por classe de sítio)
- **Método espectral** (resposta linear elástica)

Aplicações principais: **OAE (pontes, viadutos), Ferrovias, Metrô, Túneis** — fases de projeto básico e executivo (EVTE, PB, PE).

```
  ├─ Retornar erro: "location_outside_usgs_coverage"
  └─ Sugerir zoom para zona conhecida

SE timeout > 5s:
  ├─ Abortar, retry com coordenada interpolada (grid vizinho)
  └─ LOG: "API timeout, using interpolation"
```

```
  ├─ Implementar queue com token bucket

  └─ Priorizar cache hits (evita hits desnecessários)
```

## 6. CLASSIFICAÇÃO NEHRP E LOOKUP FA/FV

### 6.1 Classificação de Sítio

| Classe | Descrição | Vs30 (m/s) | Su ou Spt |
|--------|-----------|------------|-----------|
| **A** | Rocha dura | > 1500 | — |
| **B** | Rocha média | 760–1500 | — |
| **C** | Solo denso/rocha alterada | 360–760 | > 50 SPT |
| **D** | Solo rígido (default Brasil) | 180–360 | 15–50 SPT |
| **E** | Solo mole | 90–180 | < 15 SPT |
| **F** | Requer investigação especial | < 90 | — |

**Lógica de Classificação:**
```
SE Vs30 ≥ 1500 → classe = "A"
SENÃO SE Vs30 ≥ 760 → classe = "B"
SENÃO SE Vs30 ≥ 360 → classe = "C"
SENÃO SE Vs30 ≥ 180 → classe = "D"
SENÃO SE Vs30 ≥ 90 → classe = "E"
SENÃO → classe = "F" (requer investigação)
```

### 6.2 Tabelas NEHRP 2020 — Fa (Curto Período, T ≈ 0.3 s)

| Classe | SS = 0.5g | SS = 0.75g | SS = 1.0g | SS = 1.25g |
|--------|-----------|-----------|----------|-----------|
| A/B | 0.8 | 0.8 | 0.8 | 0.8 |
| C | 1.2 | 1.2 | 1.1 | 1.0 |
| D | 1.6 | 1.4 | 1.2 | 1.1 |
| E | 2.5 | 1.7 | 1.2 | 0.9 |
| F | 3.5 | 3.2 | 2.8 | 2.4 |

**Nota:** SS = "spectral acceleration at short periods" obtido de USGS.

### 6.3 Tabelas NEHRP 2020 — Fv (Períodos Longos, T ≈ 1.0 s)

| Classe | S1 = 0.1g | S1 = 0.2g | S1 = 0.3g | S1 = 0.4g |
|--------|----------|----------|----------|----------|
| A/B | 0.8 | 0.8 | 0.8 | 0.8 |
| C | 1.5 | 1.5 | 1.5 | 1.4 |
| D | 2.4 | 2.0 | 1.8 | 1.6 |
| E | 3.5 | 3.2 | 2.8 | 2.4 |
| F | 4.2 | 4.0 | 3.6 | 3.2 |

**Nota:** S1 = "spectral acceleration at 1 s period".

### 6.4 Algoritmo de Lookup

```
ENTRADA: site_class, pga_usgs
SAÍDA: Fa, Fv

% Estimar SS a partir de PGA (regressão empírica NEHRP)
SS = PGA_USGS × 2.5  // fator aproximado para Brasil

% Interpolação linear em tabela Fa
SE SS < 0.5g:
  Fa = tabela_fa[class][0.5]
SENÃO SE SS > 1.25g:
  Fa = tabela_fa[class][1.25]
SENÃO:
  índice = (SS - 0.5) / 0.25
  Fa = lerp(tabela_fa[class][i], tabela_fa[class][i+1], frac)

% Análogo para Fv com S1
S1 = PGA_USGS / 4.0  // fator para conversão a 1s
[aplicar interpolação análoga]

RETORNAR (Fa, Fv)
```

## 7. CÁLCULO DO ESPECTRO DE RESPOSTA Sa(T)

### 7.1 Fundamentos

O espectro de resposta inelástico é calculado como:

$$S_a(T) = \frac{2\pi}{T^2} \cdot S_d(T) = \frac{S_v(T)}{T}$$

onde:
- $S_d$ = espectro de deslocamento (cm)
- $S_v$ = espectro de velocidade (cm/s)
- $S_a$ = espectro de aceleração (g ou m/s²)

### 7.2 Espectro de Resposta Elástico (5% amortecimento)

Para **períodos curtos (T < 0.3 s):**
```
Sa(T) = a₀ + (Ss - a₀) × (Ts / T)^n
onde:
  a₀ = Fa × PGA
  Ss = Fa × SS (aceleração espectral @ T = 0.3s)
  Ts = período de transição ≈ 0.3 s
  n = 2.0
```

Para **períodos intermediários (0.3 s ≤ T < T1):**
```
Sa(T) = Ss  (patmar constante)
```

Para **períodos longos (T ≥ T1):**
```
Sa(T) = Fv × S1 / T
onde:
  S1 = aceleração espectral @ T = 1.0s
  T1 = período de transição ≈ 1.0 s
```

### 7.3 Pseudo-código: SpectrumGenerator

```python
def spectrum_elastic(periods: List[float], 
                      pga: float, 
                      ss: float, 
                      s1: float,
                      fa: float,
                      fv: float) -> List[float]:
    """
    periods: array de períodos [0.01, 0.1, 0.5, 1.0, 2.0, 3.0] s
    pga, ss, s1: acelerações em g (USGS)
    fa, fv: fatores de amplificação NEHRP
    retorna: array Sa(T) em g
    """
    sa = []
    a0 = fa * pga
    ss_design = fa * ss
    s1_design = fv * s1
    
    for t in periods:
        if t < 0.01:  # limite inferior
            sa_t = a0
        elif t <= 0.3:  # região aceleração (short period)
            ts = 0.3
            n = 2.0
            sa_t = a0 + (ss_design - a0) * (ts / t)**n
        elif t <= 1.0:  # região patmar (constant)
            sa_t = ss_design
        else:  # região velocidade (long period)
            t0 = 1.0
            sa_t = (s1_design / t)  # ou: (s1_design × t0 / t)
        
        sa.append(sa_t)
    
    return sa
```

## 8. PSEUDOCÓDIGO COMPLETO

### 8.1 Classe PGACalculator (Main Orchestrator)

```python
class PGACalculator:
    """
    Calculadora principal de PGA e espectro de resposta.
    """
    
    def __init__(self):
        self.usgs_client = USGSClient(timeout=5, retries=3)
        self.nehrp_classifier = NehrpClassifier()
        self.spectrum_gen = SpectrumGenerator()
        self.cache = CacheManager(ttl_hours=24)
    
    def calculate(self, latitude: float, 
                         longitude: float,
                         vs30_optional: Optional[float] = None,
                         periods: List[float] = None) -> dict:
        """
        Endpoint principal.
        
        Returns: dict com pga_g, site_class, fa, fv, sa_spectrum
        """
        
        # Validação de entrada
        validate_coordinates(latitude, longitude)
        
        # Verificar cache
        cache_key = f"{latitude:.4f}_{longitude:.4f}"
        if cached_result := self.cache.get(cache_key):
            return cached_result
        
        # 1. Obter PGA de USGS
        try:
            usgs_hazard = self.usgs_client.fetch_pga(
                latitude, longitude, 
                return_period=475
            )
            pga_g = usgs_hazard['hazard']['pga']
            ss = pga_g * 2.5  # conversão heurística
            s1 = pga_g / 4.0
        except USGSUnavailableError:
            log.warning("USGS unavailable, using fallback")
            pga_g = fallback_pga_map[latitude, longitude]
        
        # 2. Obter ou inferir Vs30
        if vs30_optional:
            vs30 = vs30_optional
        else:
            vs30 = self.usgs_client.fetch_vs30(latitude, longitude)
            if vs30 is None:
                vs30 = 350.0  # default classe D
        
        # 3. Classificar NEHRP
        site_class = self.nehrp_classifier.classify(vs30)
        
        # 4. Lookup Fa, Fv
        fa = self.nehrp_classifier.lookup_fa(site_class, ss)
        fv = self.nehrp_classifier.lookup_fv(site_class, s1)
        
        # 5. Gerar espectro
        if periods is None:
            periods = [0.01, 0.1, 0.5, 1.0, 1.5, 2.0, 3.0]
        
        sa_spectrum = self.spectrum_gen.spectrum_elastic(
            periods, pga_g, ss, s1, fa, fv
        )
        
        # 6. Montar resposta
        result = {
            "pga_g": round(pga_g, 4),
            "pga_m_s2": round(pga_g * 9.81, 3),
            "site_class_nehrp": site_class,
            "vs30_m_s": vs30,
            "fa": fa,
            "fv": fv,
            "periodos": periods,
            "sa_spectrum": [round(s, 4) for s in sa_spectrum],
            "usgs_source": "earthquake-hazards-program",
            "return_period": 475,
            "metadata": {
                "request_id": uuid4(),
                "timestamp": utcnow().isoformat(),
                "model_version": "NEHRP-2020"
            }
        }
        
        # 7. Cache
        self.cache.set(cache_key, result)
        
        return result
```

### 8.2 Classe USGSClient

```python
class USGSClient:
    """Interface com USGS Earthquake Hazards."""
    
    BASE_URL = "https://earthquake.usgs.gov/earthquakes/events/"
    
    def __init__(self, timeout=5, retries=3):
        self.timeout = timeout
        self.retries = retries
        self.session = requests.Session()
    
    def fetch_pga(self, lat: float, lon: float, 
                   return_period: int = 475) -> dict:
        """
        Busca PGA para uma coordenada via USGS API.
        """
        url = f"{self.BASE_URL}hazards/static/data/probabilistic_data"
        params = {
            "latitude": lat,
            "longitude": lon,
            "vs30": "reference",
            "return_period": return_period
        }
        
        for attempt in range(self.retries):
            try:
                resp = self.session.get(
                    url, 
                    params=params, 
                    timeout=self.timeout
                )
                resp.raise_for_status()
                return resp.json()
            except (requests.Timeout, requests.ConnectionError):
                wait_time = 2**attempt  # backoff exponencial
                log.warning(f"USGS timeout, retry {attempt+1}/{self.retries}, waiting {wait_time}s")
                sleep(wait_time)
            except requests.HTTPError as e:
                if resp.status_code == 404:
                    raise LocationOutsideCoverageError()
                log.error(f"USGS HTTP {resp.status_code}: {e}")
                raise
        
        raise USGSUnavailableError("Max retries exceeded")
    
    def fetch_vs30(self, lat: float, lon: float) -> Optional[float]:
        """Busca Vs30 estimado para uma coordenada."""
        url = f"{self.BASE_URL}services/hazards/vs30"
        params = {"latitude": lat, "longitude": lon, "model": "default"}
        
        try:
            resp = self.session.get(url, params=params, timeout=self.timeout)
            if resp.status_code == 200:
                data = resp.json()
                return data.get("vs30_m_s")
        except Exception as e:
            log.warning(f"Vs30 fetch failed: {e}")
        
        return None  # fallback no caller
```

### 8.3 Classe NehrpClassifier

```python
class NehrpClassifier:
    """Classificação NEHRP 2020."""
    
    SITE_CLASS_THRESHOLDS = {
        "A": (1500, float('inf')),
        "B": (760, 1500),
        "C": (360, 760),
        "D": (180, 360),
        "E": (90, 180),
        "F": (0, 90)
    }
    
    # Tabela Fa interpolada
    FA_TABLE = {
        "A": {0.5: 0.8, 0.75: 0.8, 1.0: 0.8, 1.25: 0.8},
        "B": {0.5: 0.8, 0.75: 0.8, 1.0: 0.8, 1.25: 0.8},
        "C": {0.5: 1.2, 0.75: 1.2, 1.0: 1.1, 1.25: 1.0},
        "D": {0.5: 1.6, 0.75: 1.4, 1.0: 1.2, 1.25: 1.1},
        "E": {0.5: 2.5, 0.75: 1.7, 1.0: 1.2, 1.25: 0.9},
        "F": {0.5: 3.5, 0.75: 3.2, 1.0: 2.8, 1.25: 2.4}
    }
    
    # Tabela Fv análoga
    FV_TABLE = {
        "A": {0.1: 0.8, 0.2: 0.8, 0.3: 0.8, 0.4: 0.8},
        "B": {0.1: 0.8, 0.2: 0.8, 0.3: 0.8, 0.4: 0.8},
        "C": {0.1: 1.5, 0.2: 1.5, 0.3: 1.5, 0.4: 1.4},
        "D": {0.1: 2.4, 0.2: 2.0, 0.3: 1.8, 0.4: 1.6},
        "E": {0.1: 3.5, 0.2: 3.2, 0.3: 2.8, 0.4: 2.4},
        "F": {0.1: 4.2, 0.2: 4.0, 0.3: 3.6, 0.4: 3.2}
    }
    
    def classify(self, vs30: float) -> str:
        """Vs30 em m/s → classe NEHRP."""
        for cls, (min_vs, max_vs) in self.SITE_CLASS_THRESHOLDS.items():
            if min_vs <= vs30 < max_vs:
                return cls
        return "F"  # fallback
    
    def lookup_fa(self, site_class: str, ss: float) -> float:
        """Interpolação linear em tabela Fa."""
        return self._interpolate_table(self.FA_TABLE[site_class], ss)
    
    def lookup_fv(self, site_class: str, s1: float) -> float:
        """Interpolação linear em tabela Fv."""
        return self._interpolate_table(self.FV_TABLE[site_class], s1)
    
    def _interpolate_table(self, table: dict, x: float) -> float:
        """Interpolação linear entre pontos tabelados."""
        keys = sorted(table.keys())
        
        if x <= keys[0]:
            return table[keys[0]]
        if x >= keys[-1]:
            return table[keys[-1]]
        
        # Encontrar intervalo
        for i in range(len(keys) - 1):
            x0, x1 = keys[i], keys[i + 1]
            if x0 <= x <= x1:
                y0, y1 = table[x0], table[x1]
                # Interpolação linear
                t = (x - x0) / (x1 - x0)
                return y0 + t * (y1 - y0)
        
        return table[keys[-1]]
```

## 10. VALIDAÇÃO E LIMITES

### 10.1 Validação de Saída

```
VALIDAR Sa(T):
  ├─ Sa(T) ≥ 0 para todo T
  ├─ Sa(T) ≥ fa × pga para T < 0.3s (floor)
  ├─ Sa(T) ≤ fa × Ss para 0.3s ≤ T ≤ 1.0s (ceiling)
  └─ Sa(T) ≤ max(Fa, Fv) × pga para T > 1.0s

VALIDAR monotonia (se período aumenta, Sa NÃO deve oscilar erraticamente):
  └─ Aplicar suavização se detectar ruído acima de 5%
```

### 10.2 Limites de Aplicabilidade

| Parâmetro | Limite | Ação se violado |
|-----------|--------|-----------------|
| Latitude | -33.5 a -5.0 | Erro: "outside Brazil coverage" |
| Longitude | -75.0 a -30.0 | Erro: "outside Brazil coverage" |
| Vs30 | 50–2000 m/s | Aviso se < 100 ou > 1500 |
| Período T | 0.01–5.0 s | Truncar fora deste intervalo |
| Amortecimento | 5% fixo | Aviso se usuário tenta mudar |

### 10.3 Incerteza & Reportar Intervalo de Confiança

```
USGS fornece incerteza:
  lower_mean = PGA × 0.9  (p16)
  mean = PGA
  upper_mean = PGA × 1.11  (p84)

REPORTAR intervalo:
  "uncertainty": {
    "lower_g": 0.078,
    "median_g": 0.087,
    "upper_g": 0.097,
    "percentile_ci": "16-84"
  }
```
