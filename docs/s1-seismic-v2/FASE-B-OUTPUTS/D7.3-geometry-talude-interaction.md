# D7.3 — Geometry-Talude Interaction (Feedback Loop D6.3 → D7 Redesign)

**Especificação Técnica**  
Versão: 1.0  
Data: 2026-07-25  
Segmento: Geotecnia — Redesign de Geometria via Deformações Newmark  
Prioridade: Alta (afeta estabilidade e custos de obra)

---

## 1. Introdução

O **D7.3 — Geometry-Talude Interaction** implementa o feedback loop entre análise de
deformações sísmicas (D6.3 — Newmark) e redesign de geometria de taludes (D7). 

A especificação responde à seguinte pergunta:

> **Se a deformação permanente (Newmark) em um talude de corte ultrapassa 0.5 m,
> como deve a geometria ser iterativamente ajustada para trazer o deslocamento
> dentro de limites aceitáveis?**

**Fluxo D6.3 → D7.3 → D7:**

```
Input (D6.3)
  ↓ [Newmark Calculator]
  ↓ deformation_newmark (m)
  ↓
  ├─→ [CRITÉRIO] deformation_newmark > 0.5 m ?
  │     ├─ SIM → D7.3 Geometry Redesign Loop
  │     │         (aumenta raio de curvatura, reduz inclinação)
  │     │         ↓ OUTPUT: geometry_recommendations
  │     │
  │     └─ NÃO → D7 Normal Design (sem iteração)
  │
Output (D7)
  ↓ [Geometry Verification]
  ↓ geometry_optimized
```

**Aplicabilidade:**
- Taludes de corte em rodovias (seção horizontal e vertical)
- Projeto em fase de Projeto Básico e Executivo
- Solicitação: AySA, DNIT, concedentes (análise de risco sísmico)

---

## 2. Critério de Disparo e Métricas

### 2.1 Limite de Deformação Aceitável

Define-se o **deslocamento permanente crítico** como:

| Cenário | Limite Newmark | Trigger D7.3 |
|---------|----------------|----|
| Taludes em zona sísmica de alta atividade (≥0.2g) | 0.3 m | > 0.3 m |
| Taludes em zona intermediária (0.1–0.2g) | 0.5 m | > 0.5 m |
| Taludes em zona de baixa atividade (<0.1g) | 1.0 m | > 1.0 m |
| Taludes críticos (com estruturas ou VUP) | 0.15 m | > 0.15 m |

**Padrão adotado para Jericó (ABNT NBR 15421 — zona intermediária):** 
**Limite = 0.5 m**

### 2.2 Métricas de Desempenho (D7.3)

Para cada iteração, avaliam-se:

1. **FS (Fator de Segurança estático)**
   - Entrada: inclinação β, coesão c, ângulo de atrito φ, altura H
   - Aceitável: FS ≥ 1.3 (corte) / FS ≥ 1.5 (aterro)

2. **FS_dinâmico (Newmark recalculado)**
   - Entrada: geometria redesenhada
   - Critério: deformation < limite aceitável

3. **Custo incremental**
   - Volume escavado adicional (m³)
   - Custo por m³ da região
   - Benefício: redução de risco sísmico

4. **Convergência**
   - Tolerância: |deformation_i − deformation_{i-1}| < 0.05 m
   - Máximo de iterações: 10

---

## 3. Algoritmo Iterativo de Redesign

### 3.1 Estratégia de Ajuste Geométrico

Quando `deformation_newmark > limite_aceitável`, aplicam-se **sequencialmente**:

| Iteração | Ação Primária | Ação Secundária | Parâmetro Ajustado |
|----------|---------------|-----------------|-------------------|
| 1 | Reduz inclinação β | − | β → β − 2° |
| 2 | Aumenta raio de curvatura vertical | − | Rv → Rv + 20% |
| 3 | Combina: reduz β E aumenta Rv | Berma intermédia | β − 4°, Rv + 30% |
| 4+ | Escavação adicional (alargamento) | Berma ou drenagem | H_escav adicional |

**Lógica de parada:**
- Se `deformation < limite_aceitável` → termina (convergência)
- Se `iterações ≥ 10` → retorna melhor solução parcial + aviso

### 3.2 Parâmetros Geométricos Ajustáveis

```
Talude de Corte Original:
├─ inclinação_original (β₀) [graus]
├─ altura_original (H₀) [m]
├─ raio_vertical_original (Rv₀) [m]
└─ drenagem_tipo [superficial|interna|ausente]

Parâmetros de Redesign:
├─ β_min = 25° [limite mínimo prático]
├─ Rv_max = 500 m [limite de curvatura por segurança]
├─ H_escav_adicional [m de aprofundamento]
└─ berm_width [m de berma intermediária]
```

## 4. Pseudocódigo do Algoritmo Iterativo

```pseudocode
ALGORITMO GeometryTaludeInteraction_D7.3
────────────────────────────────────────

INPUT:
  geometry_baseline {β, H, Rv, c, φ, γ, a_max}  // Design original (D7 baseline)
  deformation_newmark [m]                         // Resultado D6.3
  limite_aceitavel_deformacao [m]                 // Tabela 2.1
  iteracao_max = 10                               // Máximo de tentativas
  tolerancia_convergencia = 0.05 [m]              // Critério de parada

OUTPUT:
  geometry_optimized {β, H, Rv, berm, cost_delta}
  iteracoes_totais [count]
  convergencia_alcancada [bool]
  deformation_final [m]

VARIÁVEIS LOCAIS:
  iter ← 0
  deformation_anterior ← deformation_newmark
  geometry_atual ← geometry_baseline
  melhor_geometry ← geometry_baseline
  melhor_deformation ← deformation_newmark

────────────────────────────────────────
1. VALIDAÇÃO INICIAL
────────────────────────────────────────

SE (deformation_newmark ≤ limite_aceitavel_deformacao) ENTÃO
  RETORNA {
    status: "OK_SEM_REDESIGN",
    geometry_optimized: geometry_baseline,
    iteracoes_totais: 0,
    convergencia_alcancada: verdadeiro,
    deformation_final: deformation_newmark
  }
FIM SE

REGISTRA "Disparo D7.3: deformation (%.2f m) > limite (%.2f m)" 
         [deformation_newmark, limite_aceitavel_deformacao]

────────────────────────────────────────
2. LOOP ITERATIVO
────────────────────────────────────────

ENQUANTO (iter < iteracao_max) FAÇA

  iter ← iter + 1
  REGISTRA "Iteração %d", iter

  ╔═════════════════════════════════════════════════════════════╗
  ║ 2.A — SELEÇÃO DE ESTRATÉGIA DE AJUSTE                      ║
  ╚═════════════════════════════════════════════════════════════╝

  SE (iter == 1) ENTÃO
    ┌─ ESTRATÉGIA 1: Redução de Inclinação
    │
    β_novo ← geometry_atual.β − 2.0 [graus]
    SE (β_novo < 25) ENTÃO
      β_novo ← 25  // limite mínimo
    FIM SE
    
    geometry_proposta ← geometry_atual
    geometry_proposta.β ← β_novo
    geometry_proposta.Rv ← geometry_atual.Rv
    
    ação_descrita ← "Redução de inclinação de %.1f° para %.1f°"
                    [geometry_atual.β, β_novo]
    └─

  SENÃO SE (iter == 2) ENTÃO
    ┌─ ESTRATÉGIA 2: Aumento de Raio Vertical
    │
    Rv_novo ← geometry_atual.Rv × 1.20  // +20%
    SE (Rv_novo > 500) ENTÃO
      Rv_novo ← 500  // limite máximo
    FIM SE
    
    geometry_proposta ← geometry_atual
    geometry_proposta.Rv ← Rv_novo
    geometry_proposta.β ← geometry_atual.β
    
    ação_descrita ← "Aumento de Rv: %.1f m → %.1f m"
                    [geometry_atual.Rv, Rv_novo]
    └─

  SENÃO SE (iter == 3) ENTÃO
    ┌─ ESTRATÉGIA 3: Combinada (β + Rv)
    │
    β_novo ← geometry_atual.β − 4.0
    Rv_novo ← geometry_atual.Rv × 1.30  // +30%
    
    SE (β_novo < 25) ENTÃO β_novo ← 25 FIM SE
    SE (Rv_novo > 500) ENTÃO Rv_novo ← 500 FIM SE
    
    geometry_proposta ← geometry_atual
    geometry_proposta.β ← β_novo
    geometry_proposta.Rv ← Rv_novo
    geometry_proposta.berm_width ← 3.0  // berma intermédia
    
    ação_descrita ← "Combinada: β=%.1f°, Rv=%.1f m, berm=3.0m"
                    [β_novo, Rv_novo]
    └─

  SENÃO  // iter ≥ 4
    ┌─ ESTRATÉGIA 4+: Escavação Adicional
    │
    H_escav_adicional ← 1.5 × (iter − 3)  // 1.5 m, 3.0 m, ...
    
    geometry_proposta ← geometry_atual
    geometry_proposta.H_escavacao_adicional ← H_escav_adicional
    
    // Mantém β e Rv, mas amplia seção de corte
    ação_descrita ← "Escavação adicional: %.1f m"
                    [H_escav_adicional]
    └─

  FIM SE

  ╔═════════════════════════════════════════════════════════════╗
  ║ 2.B — VERIFICAÇÃO ESTÁTICA (FS)                            ║
  ╚═════════════════════════════════════════════════════════════╝

  FS_estatico ← CalcularFS_Bishop(geometry_proposta)
  
  REGISTRA "  FS estático: %.2f", FS_estatico
  
  SE (FS_estatico < 1.3) ENTÃO
    REGISTRA "  FALHA: FS < 1.3, rejeita proposta"
    CONTINUA  // próxima iteração
  FIM SE

  ╔═════════════════════════════════════════════════════════════╗
  ║ 2.C — RECÁLCULO NEWMARK (D6.3 revisado)                    ║
  ╚═════════════════════════════════════════════════════════════╝

  deformation_proposta ← RecalcularNewmark_D6_3(
    geometry: geometry_proposta,
    a_max: geometry_baseline.a_max,
    magnitude: geometry_baseline.magnitude
  )
  
  REGISTRA "  Deformation Newmark: %.3f m (anterior: %.3f m)"
           [deformation_proposta, deformation_anterior]

  ╔═════════════════════════════════════════════════════════════╗
  ║ 2.D — VERIFICAÇÃO DE CONVERGÊNCIA                          ║
  ╚═════════════════════════════════════════════════════════════╝

  delta_deformation ← ABS(deformation_proposta − deformation_anterior)
  
  REGISTRA "  Δ deformation: %.3f m (tolerância: %.3f m)"
           [delta_deformation, tolerancia_convergencia]

  SE (deformation_proposta ≤ limite_aceitavel_deformacao) ENTÃO
    
    REGISTRA "✓ CONVERGÊNCIA ALCANÇADA na iteração %d", iter
    
    geometry_otimizada ← geometry_proposta
    geometry_otimizada.iteracao_convergencia ← iter
    geometry_otimizada.deformation_final ← deformation_proposta
    geometry_otimizada.delta_volume_escavacao ← CalcularVolumeDelta(
      geometry_baseline, geometry_proposta
    )
    
    RETORNA {
      status: "CONVERGENCIA_OK",
      geometry_optimized: geometry_otimizada,
      iteracoes_totais: iter,
      convergencia_alcancada: verdadeiro,
      deformation_final: deformation_proposta,
      acao_executada: ação_descrita,
      fs_final: FS_estatico,
      cost_delta_estimado: geometry_otimizada.delta_volume_escavacao × 
                           CUSTO_ESCAVACAO_REGIONAL
    }
    
  FIM SE

  ╔═════════════════════════════════════════════════════════════╗
  ║ 2.E — REGISTRO DE MELHOR SOLUÇÃO PARCIAL                   ║
  ╚═════════════════════════════════════════════════════════════╝

  SE (deformation_proposta < melhor_deformation) ENTÃO
    melhor_geometry ← geometry_proposta
    melhor_deformation ← deformation_proposta
  FIM SE

  ╔═════════════════════════════════════════════════════════════╗
  ║ 2.F — PREPARAÇÃO PRÓXIMA ITERAÇÃO                          ║
  ╚═════════════════════════════════════════════════════════════╝

  geometry_atual ← geometry_proposta
  deformation_anterior ← deformation_proposta

FIM ENQUANTO

────────────────────────────────────────
3. PÓS-LOOP: MELHOR SOLUÇÃO PARCIAL
────────────────────────────────────────

REGISTRA "⚠ Máximo de iterações (%d) atingido sem convergência"
         [iteracao_max]
REGISTRA "  Melhor solução parcial: deformation = %.3f m"
         [melhor_deformation]

SE (melhor_deformation < limite_aceitavel_deformacao) ENTÃO
  status ← "PARCIAL_ACEITAVEL"
  convergencia ← verdadeiro
SENÃO
  status ← "FALHA_REDESIGN"
  convergencia ← falso
FIM SE

RETORNA {
  status: status,
  geometry_optimized: melhor_geometry,
  iteracoes_totais: iteracao_max,
  convergencia_alcancada: convergencia,
  deformation_final: melhor_deformation,
  aviso: "Máximo de iterações atingido. Verificar manualmente. " +
         "Considerar: drenagem, reforço ou realocação do talude.",
  cost_delta_estimado: CalcularVolumeDelta(geometry_baseline, 
                                           melhor_geometry) × 
                       CUSTO_ESCAVACAO_REGIONAL
}

════════════════════════════════════════════════════════════════
FIM ALGORITMO
════════════════════════════════════════════════════════════════
```

## 5. Critério de Convergência

### 5.1 Definição

Convergência é atingida quando **qualquer uma** das seguintes condições é satisfeita:

| Critério | Expressão | Prioridade |
|----------|-----------|-----------|
| **Deformação aceitável** | $\text{def}_n ≤ L_{aceitável}$ | Primária |
| **Melhora mínima** | $\|\text{def}_n - \text{def}_{n-1}\| < 0.05$ m | Secundária |
| **Limite de iterações** | $n ≥ 10$ | Terciária |

### 5.2 Saída de Convergência

Ao atingir convergência, a função retorna:

```json
{
  "status": "CONVERGENCIA_OK",
  "geometry_optimized": {
    "inclination_beta": 30.0,           // graus
    "height": 12.5,                     // m
    "radius_vertical": 125.0,           // m
    "berm_width": 3.0,                  // m (se aplicável)
    "H_escavacao_adicional": 0.0        // m
  },
  "deformation_final": 0.48,            // m (< 0.5)
  "iteracoes_totais": 2,
  "fs_final": 1.35,                     // Fator de segurança
  "delta_volume": 450,                  // m³ de escavação extra
  "custo_delta_estimado": 13500,        // R$ (a R$ 30/m³)
  "convergencia_alcancada": true,
  "tempo_execucao": 0.42                // segundos
}
```

## 7. Implementação — Funções Auxiliares

### 7.1 CalcularFS_Bishop(geometry)

```pseudocode
FUNÇÃO CalcularFS_Bishop(geometry) → FS_estático

  // Entrada: geometry com {β, H, c, φ, γ}
  // Saída: Fator de segurança pelo método Bishop simplificado
  
  β_rad ← geometry.β × π / 180
  H ← geometry.H
  c ← geometry.c
  φ ← geometry.φ
  γ ← geometry.γ
  
  // Altura crítica (talud infinito)
  H_crit ← (4 × c) / (γ × SIN(2 × β_rad))
  
  // Fator de altura
  f_altura ← 1.0 + (H_crit / H) × 0.5
  
  // Fator de geometria (curvatura)
  SE (geometry.Rv > 200) ENTÃO
    f_curvatura ← 1.05  // curvatura suave, adiciona margem
  SENÃO SE (geometry.Rv > 100) ENTÃO
    f_curvatura ← 1.02  // curvatura moderada
  SENÃO
    f_curvatura ← 1.00  // sem benefício
  FIM SE
  
  // FS Bishop simplificado
  FS_base ← (c / (γ × H × SIN(β_rad) × COS(β_rad))) + 
            (COT(β_rad) × TAN(φ))
  
  FS_final ← FS_base × f_curvatura × f_altura
  
  RETORNA FS_final
FIM FUNÇÃO
```

### 7.2 RecalcularNewmark_D6_3(geometry, a_max, magnitude)

```pseudocode
FUNÇÃO RecalcularNewmark_D6_3(geometry, a_max, magnitude) → deformation [m]

  // Entrada: geometria redesenhada, parâmetros sísmicos
  // Saída: deformação permanente Newmark revisada
  
  // Passo 1: Recalcular FS_dinâmico com β novo
  FS_dinamico_novo ← CalcularFS_Bishop_Dinamico(geometry, a_max)
  
  // Passo 2: Se FS_dinâmico < 1.0, usar Newmark padrão
  SE (FS_dinamico_novo < 1.0) ENTÃO
  
    ln_A ← 10.874 − 4.844 × LN(FS_dinamico_novo)
    A ← EXP(ln_A)  // aceleração crítica [g]
    
    // Parâmetro de Newmark
    k_y ← A × 9.81  // [m/s²]
    
    // Deslocamento Newmark
    v_max ← a_max × 9.81  // velocidade max [m/s] — simplificado
    
    deformation ← (v_max² / (2 × π × k_y)) × 
                  EXP(−(FS_dinamico_novo − 1.0) / 0.25)
    
    deformation ← MÁXIMO(deformation, 0.01)  // mínimo fisicamente viável
    
  SENÃO
    deformation ← 0.0  // estável dinamicamente
  FIM SE
  
  RETORNA deformation

FIM FUNÇÃO
```

### 7.3 CalcularVolumeDelta(geometry_base, geometry_proposta)

```pseudocode
FUNÇÃO CalcularVolumeDelta(geo_base, geo_prop) → delta_volume [m³]

  // Aproximação: diferença de área da seção transversal × comprimento
  
  // Área baseline
  area_base ← CalcularAreaTalud(geo_base.β, geo_base.H, geo_base.Rv)
  
  // Área proposta
  area_prop ← CalcularAreaTalud(geo_prop.β, geo_prop.H, geo_prop.Rv)
  
  // Se há berma, adiciona área
  SE (geo_prop.berm_width > 0) ENTÃO
    area_prop ← area_prop + (geo_prop.berm_width × geo_prop.H)
  FIM SE
  
  delta_area ← area_prop − area_base
  
  // Comprimento típico do corte (p/ Jericó, ~850m)
  comprimento ← 850  // m (input do projeto)
  
  delta_volume ← delta_area × comprimento
  
  RETORNA MÁXIMO(delta_volume, 0)  // não nega redução de escavação

FIM FUNÇÃO
```

- [ ] **Física:** FS estático ≥ 1.3 antes de aceitar geometria
- [ ] **Convergência:** Máx 10 iterações; se não convergir, gera aviso
- [ ] **Sensibilidade:** Testar c ±10%, φ ±2°, a_max ±0.1g
- [ ] **Caso-teste Jericó:** Validar contra cálculo manual (Bishop + Newmark)
- [ ] **Integração D6.3:** Confirmar que Newmark recalculado usa mesma magnitude M
- [ ] **Orçamento:** Custo delta realista (pesquisar SICRO / BDI regional)
