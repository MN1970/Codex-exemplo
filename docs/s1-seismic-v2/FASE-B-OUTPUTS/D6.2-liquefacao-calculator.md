## 1. Introdução

O **Liquefação Calculator** implementa a metodologia **Tokimatsu & Yoshida (1989)** para
avaliação do potencial de liquefação de solos granulares sob carregamento sísmico. A ferramenta:

- Calcula o **Índice de Liquefação (LI)** na escala 0–4
- Integra dados SPT (ensaio padrão de penetração)
- Caracteriza o sítio mediante peso específico, tensão efetiva vertical
- Fornece recomendações de remediação progressivas

**Aplicabilidade geográfica:** Região de Jericó (caso-teste), adaptável a outros sítios
com entradas e calibração locais.

---

## 2. Formulação Matemática

### 2.1 Fator de Segurança à Liquefação (FS)

O fator de segurança contra liquefação é dado por:

$$
FS = \frac{\text{CSR}}{\text{CRR}}
$$

Onde:

- **CSR** = Razão de tensão cíclica (Cyclic Stress Ratio) — tensão cisalhante induzida pela onda sísmica
- **CRR** = Razão de resistência cíclica (Cyclic Resistance Ratio) — capacidade do solo de resistir ao cisalhamento cíclico

### 2.2 CSR — Razão de Tensão Cíclica

$$
\text{CSR} = \frac{\tau_{av}}{\sigma'_{vo}} = 0.65 \cdot \frac{a_{max}}{g} \cdot \frac{\sigma_{vo}}{\sigma'_{vo}} \cdot rd
$$

Onde:

- $a_{max}$ = aceleração máxima do terreno (m/s²)
- $g$ = aceleração da gravidade (9.81 m/s²)
- $\sigma_{vo}$ = tensão vertical total
- $\sigma'_{vo}$ = tensão vertical efetiva
- $rd$ = fator de redução de rigidez em profundidade

**Fator $rd$ (profundidade):**

$$
rd = 1 - 0.015 \cdot z \quad \text{(para } z \le 30 \text{ m)}
$$

Onde $z$ = profundidade em metros.

### 2.3 CRR — Razão de Resistência Cíclica (Tokimatsu & Yoshida)

Baseado no número de pancadas SPT corrigido para energia (N₆₀):

$$
\text{CRR} = \frac{1}{34 - (N_{60})^{0.05}} + \frac{(N_{60})}{135} - \frac{50}{[10 \cdot (N_{60}) + 45]^2} + 0.2
$$

Simplificação prática (para uso de ferramentas):

$$
\text{CRR}_{simplificado} = \frac{1}{25 + 1.5 \cdot (N_{60})^{-1.2}}
$$

**Ajustes por profundidade e confinamento:**

- Para $z > 10$ m: aplicar fator de correção $K\sigma = 0.85 + 0.03 \cdot z$ até $K\sigma = 1.0$
- Para solos arenosos com mica ou silte: reduzir CRR em 10–15%

$$
\text{CRR}_{ajustado} = \text{CRR} \cdot K\sigma
$$

### 2.4 Índice de Liquefação (LI)

Transformação de FS em índice discreto LI (0–4):

$$
LI = 
\begin{cases}
0 & \text{se } FS > 1.5 \text{ (seguro)}\\
1 & \text{se } 1.2 < FS \le 1.5 \text{ (baixo risco)}\\
2 & \text{se } 0.9 < FS \le 1.2 \text{ (risco moderado)}\\
3 & \text{se } 0.5 < FS \le 0.9 \text{ (risco elevado)}\\
4 & \text{se } FS \le 0.5 \text{ (crítico)}
\end{cases}
$$

## 4. Pseudocódigo

```
ALGORITMO: CalcularLiquefacao(z, N, NF, γd, γsat, amax_g)
ENTRADA:
  z          → profundidade (m)
  N          → SPT bruto (golpes/30cm)
  NF         → nível freático (m)
  γd         → peso específico seco (kN/m³)
  γsat       → peso específico saturado (kN/m³)
  amax_g     → aceleração máxima em g

SAÍDA:
  FS, CRR, CSR, LI, status_remediacao

INICIO
  // 1. Corrigir N para N₆₀ (assumir η = 70%)
  N60 = (70 / 100) * N

  // 2. Calcular tensões
  SE z ≤ NF ENTÃO
    σv_total = γd * z
    u_poro = 0
  SENÃO
    σv_total = γd * NF + γsat * (z - NF)
    u_poro = 9.81 * (z - NF)  // em kPa
  FIM SE
  
  σv_efetiva = σv_total - u_poro
  
  // 3. Calcular CSR
  amax_m_s2 = amax_g * 9.81
  rd = MAX(1 - 0.015 * z, 0.75)  // limite inferior 0.75
  ratio_tensoes = σv_total / MAX(σv_efetiva, 1.0)  // proteção divisão por zero
  
  CSR = 0.65 * (amax_m_s2 / 9.81) * ratio_tensoes * rd
  
  // 4. Calcular CRR (Tokimatsu & Yoshida)
  SE N60 > 0 ENTÃO
    CRR_base = 1.0 / (34.0 - (N60)^0.05) + N60/135.0 - 50/((10*N60+45)^2) + 0.2
    
    // Ajuste por profundidade
    SE z > 10 ENTÃO
      Kσ = MIN(0.85 + 0.03 * z, 1.0)
    SENÃO
      Kσ = 1.0
    FIM SE
    
    CRR = CRR_base * Kσ
  SENÃO
    CRR = 0.1  // proteção: solo muito solto
  FIM SE
  
  // 5. Calcular FS
  SE CSR ≠ 0 ENTÃO
    FS = CRR / CSR
  SENÃO
    FS = 10.0  // proteção: seguro se CSR = 0
  FIM SE
  
  // 6. Mapear FS para LI
  SE FS > 1.5 ENTÃO
    LI = 0
    status = "SEGURO"
  SENÃO SE FS > 1.2 ENTÃO
    LI = 1
    status = "BAIXO RISCO"
  SENÃO SE FS > 0.9 ENTÃO
    LI = 2
    status = "RISCO MODERADO"
  SENÃO SE FS > 0.5 ENTÃO
    LI = 3
    status = "RISCO ELEVADO"
  SENÃO
    LI = 4
    status = "CRÍTICO"
  FIM SE
  
  // 7. Recomendação de remediação
  SWITCH LI
    CASO 0, 1:
      remediacao = "Nenhuma (monitoramento)"
    CASO 2:
      remediacao = "Drenagem, melhoramento parcial"
    CASO 3:
      remediacao = "Substituição, jet grouting, consolidação dinâmica"
    CASO 4:
      remediacao = "Substituição total ou restruturação, não recomendado"
  FIM SWITCH
  
  RETORNAR (FS, CRR, CSR, LI, status, remediacao)
FIM ALGORITMO
```

### 5.3 Cálculos Exemplo — Prof. 6.0 m (z = 6.0 m, N = 10)

**Entrada:**
```
z = 6.0 m
N = 10 (SPT bruto)
NF = 6.0 m
γd = 18.0 kN/m³
γsat = 20.0 kN/m³
amax = 0.30g = 2.94 m/s²
η_SPT = 70% (fator de energia)
```

**Passo 1: Corrigir SPT**
```
N60 = 0.70 * 10 = 7.0
```

**Passo 2: Calcular Tensões (z = NF, então acima do NA)**
```
σv_total = 18.0 * 6.0 = 108.0 kPa
u_poro = 0 (ponto no topo do NA)
σv_efetiva = 108.0 - 0 = 108.0 kPa
```

**Passo 3: Calcular CSR**
```
rd = MAX(1 - 0.015 * 6.0, 0.75) = 1 - 0.09 = 0.91

ratio_tensoes = σv_total / σv_efetiva = 108.0 / 108.0 = 1.0

CSR = 0.65 * (2.94 / 9.81) * 1.0 * 0.91
    = 0.65 * 0.30 * 1.0 * 0.91
    = 0.177
```

**Passo 4: Calcular CRR (Tokimatsu & Yoshida)**
```
CRR_base = 1/(34 - 7.0^0.05) + 7.0/135 - 50/(10*7+45)^2 + 0.2
         = 1/(34 - 1.393) + 0.0519 - 50/(115)^2 + 0.2
         = 1/32.607 + 0.0519 - 0.00378 + 0.2
         = 0.0307 + 0.0519 - 0.0038 + 0.2
         = 0.2788

Kσ (z = 6 m < 10 m) = 1.0

CRR = 0.2788 * 1.0 = 0.2788
```

**Passo 5: Calcular FS**
```
FS = CRR / CSR = 0.2788 / 0.177 = 1.575
```

**Passo 6: Mapear FS para LI**
```
FS = 1.575 > 1.5
→ LI = 0 (SEGURO)
```

**Resultado:**
| Parâmetro | Valor |
|-----------|-------|
| FS | 1.575 |
| CRR | 0.279 |
| CSR | 0.177 |
| LI | 0 |
| Status | SEGURO |
| Remediação | Nenhuma (monitoramento) |

### 5.4 Cálculos Exemplo — Prof. 8.0 m (z = 8.0 m, N = 12)

**Entrada:**
```
z = 8.0 m
N = 12 (SPT bruto)
NF = 6.0 m
γd = 17.5 kN/m³ (até NF)
γsat = 20.2 kN/m³
amax = 0.30g = 2.94 m/s²

```

**Passo 1: Corrigir SPT**
```
N60 = 0.70 * 12 = 8.4
```

**Passo 2: Calcular Tensões (z = 8.0 m > NF = 6.0 m)**
```
σv_total = γd * NF + γsat * (z - NF)
         = 17.5 * 6.0 + 20.2 * 2.0
         = 105.0 + 40.4 = 145.4 kPa

u_poro = 9.81 * (8.0 - 6.0) = 9.81 * 2.0 = 19.62 kPa

σv_efetiva = 145.4 - 19.62 = 125.78 kPa
```

**Passo 3: Calcular CSR**
```
rd = MAX(1 - 0.015 * 8.0, 0.75) = 1 - 0.12 = 0.88

ratio_tensoes = 145.4 / 125.78 = 1.1558

CSR = 0.65 * (2.94 / 9.81) * 1.1558 * 0.88
    = 0.65 * 0.30 * 1.1558 * 0.88
    = 0.1882
```

**Passo 4: Calcular CRR**
```
CRR_base = 1/(34 - 8.4^0.05) + 8.4/135 - 50/(10*8.4+45)^2 + 0.2
         = 1/(34 - 1.461) + 0.0622 - 50/(129)^2 + 0.2
         = 1/32.539 + 0.0622 - 0.003 + 0.2
         = 0.0307 + 0.0622 - 0.003 + 0.2
         = 0.2899

Kσ (z = 8 m < 10 m) = 1.0

CRR = 0.2899 * 1.0 = 0.2899
```

**Passo 5: Calcular FS**
```
FS = CRR / CSR = 0.2899 / 0.1882 = 1.539
```

**Passo 6: Mapear FS para LI**
```
FS = 1.539 > 1.5
→ LI = 0 (SEGURO)
```

## 7. Fórmulas Resumidas para Implementação

### 7.1 Forma Simplificada de Tokimatsu & Yoshida

Para uso em rotinas rápidas:

$$
\text{CRR} = \frac{1}{34.0 - (N_{60})^{0.05}} + \frac{N_{60}}{135} - \frac{50}{[10 \cdot N_{60} + 45]^2} + 0.2
$$

Limites práticos:
- $\text{CRR}_{mín} = 0.05$ (solo muito solto, N₆₀ ≤ 1)
- $\text{CRR}_{máx} = 0.90$ (solo muito denso, N₆₀ ≥ 50)

### 7.2 Fator rd (Profundidade)

Válido até z = 30 m:

$$
r_d = 1.0 - 0.015 \cdot z \quad (z \text{ em metros})
$$

Limite inferior: $r_d \ge 0.75$ para z ≥ 16.7 m.

### 7.3 Fator Kσ (Confinamento)

$$
K_\sigma = 
\begin{cases}
1.0 & \text{se } z \le 10 \text{ m}\\
\min(0.85 + 0.03 \cdot z, 1.0) & \text{se } z > 10 \text{ m}
\end{cases}
$$

### 7.4 Razão de Tensão Cíclica (CSR)

$$
\text{CSR} = 0.65 \cdot a_{\max} \cdot \frac{\sigma_{vo}}{\sigma'_{vo}} \cdot r_d
$$

Onde $a_{\max}$ já está em fração de g (ex.: 0.30 para 30% de g).

## 8. Validação e Limites

### 8.1 Hipóteses Simplificativas

1. **Solo granular:** metodologia aplica-se a areias (SP, SW) e siltes arenosos (SM, SC)
2. **Condições drenadas:** análise assume solo saturado abaixo de NA
3. **Fator de energia constante:** η_SPT = 70% (calibrado para equipamentos brasileiros)
4. **Sismo único:** design para cenário Tr = 475 anos (ABNT NBR 15421)
5. **Sem coerência:** análise não captura solos coesivos (argilosos)

### 8.2 Incertezas e Sensibilidade

| Parâmetro | Influência em FS | Variação típica | Impacto |
|-----------|------------------|-----------------|--------|
| N60 | Crescente | ±2–5 golpes | ±0.15 FS |
| amax | Linear (CSR) | ±0.05g | ±0.10 FS |
| γsat/γd | Logarítmica | ±1 kN/m³ | ±0.08 FS |
| Profundidade NF | Crítica para poro | ±2 m | ±0.20 FS |
| η_SPT | Quadrática em CRR | ±10% | ±0.12 FS |

**Recomendação:** quando LI ficar próximo a limite (ex.: FS = 1.45 próx. 1.5), realizar
análise de sensibilidade e/ou sondagem complementar.

### 8.3 Limitações Geográficas

- **Válido para Jericó:** região de sismo moderado (amax ≤ 0.35g)
- **Adaptação para outras regiões:** recalibrar amax conforme NBR 15421 (ABNT, 2017)
- **Solos lateríticos/residuais:** metodologia não se aplica diretamente; consultar literatura regional

### 11.3 Mapa de Decisão — LI vs. Ação

```
LI = 0       → SEGURO
      └─→ Nenhuma ação
           Documentar cálculo, manter monitoramento

LI = 1       → BAIXO RISCO
      └─→ Monitoramento
           Drenagem superficial, controle de NA

LI = 2       → RISCO MODERADO
      └─→ Melhoramento
           Compactação dinâmica, jet grouting, drenos

LI = 3       → RISCO ELEVADO
      └─→ Reforço estrutural
           Substituição (até 50%), piles, soil mixing

LI = 4       → CRÍTICO
      └─→ Redesenho urgente
           Relocação ou fundação profunda
           Possível inviabilidade técnico-econômica
```
