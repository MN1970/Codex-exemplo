CORE COMPONENTS
================================================================================

1. NEWMARK DEFORMATION MECHANICS
   -----------
   - Yield acceleration formula: a_y = ((FoS - 1) / FoS) × g
   - Based on Newmark (1965) sliding block analysis
   - Computes critical acceleration threshold for slope failure
   - Handles edge cases (FoS < 1.0, unstable slopes)

2. JIBSON (2007) REGRESSION MODULE
   --------------------------------
   - Empirical relationship: log₁₀(D) = α + β·log₁₀(a_max/a_y)
   - Coefficients: α = -0.4062, β = 0.3625 (literature defaults)
   - Converts PGA and yield acceleration to permanent deformation (cm)
   - Includes uncertainty quantification (regression bounds)
   - Handles no-slip condition when PGA < a_y

3. FACTOR OF SAFETY CALCULATION
   ----------------------------
   - Infinite slope analysis (homogeneous, saturated conditions)
   - Pseudostatic FoS with horizontal seismic coefficient
   - Supports soil layer variation with depth
   - Method: Bishop (1966) / Coulomb infinite slope

4. D6.2 LIQUEFACTION INTEGRATION
   ---------------------------
   - Detects liquefiable layers in soil profile
   - Reduces cohesion if liquefaction index Li > 0.3
   - Formula: c_eff = c × (1 - 0.8 × Li)
   - Cascades to lower FoS and higher permanent deformation
   - Full integration: slope_failure → liquefaction_trigger feedback

5. RISK CLASSIFICATION SYSTEM
   --------------------------
   - LOW: D < 5 cm
   - MODERATE: 5 ≤ D < 15 cm
   - HIGH: 15 ≤ D < 30 cm
   - CRITICAL: D ≥ 30 cm

6. SLIP PROBABILITY ANALYSIS
   -------------------------
   - Log-normal distribution model
   - P_slip = 1 - Φ((ln(a_y/PGA)) / σ_ln)
   - σ_ln = 0.6 (uncertainty in FoS and seismic demand)
   - Range: 0 to 1 (0% to 100%)

7. D7.3 FEEDBACK LOOP HOOK
   -----------------------
   - Evaluates intervention needs (rampa/reinforcement)
   - Decision tree: FoS threshold → recommendations
   - Tracks cumulative deformation over time
   - Suggests: drainage, geotextile, soil nails, micropiles
   - Output: Dict with FoS status, actions, deformation tracking

================================================================================
CALCULATION WORKFLOW (as implemented in SlopeStabilityAnalyzer.analyze())
================================================================================

Step 1: Compute static FoS (infinite slope)
  └─ Formula: FoS = tanφ / tanβ + cohesion_term

Step 2: Apply liquefaction correction (D6.2 integration)
  └─ Check if any layers have liquefaction_potential=True
  └─ If yes: Estimate Li index, reduce cohesion

Step 3: Verify slope stability (FoS ≥ 1.0)
  └─ Raise error if unstable before seismic input

Step 4: Compute yield acceleration
  └─ a_y = ((FoS - 1) / FoS) × g [Newmark 1965]

Step 5: Compute PGA/a_y ratio
  └─ Demand/capacity indicator

Step 6: Apply Jibson regression IF PGA > a_y
  └─ log₁₀(D) = -0.4062 + 0.3625 × log₁₀(PGA/a_y)
  └─ D = 10^(log₁₀(D)) in cm

Step 7: Compute slip probability
  └─ P_slip = 1 - Φ((ln(a_y/PGA)) / 0.6)

Step 8: Classify risk level
  └─ RiskLevel enum: LOW, MODERATE, HIGH, CRITICAL

Step 9: Return NewmarkAnalysisResult
  └─ Contains all intermediate values (analysis_log dict)
  └─ Ready for D7.3 feedback downstream

================================================================================
EXAMPLE USAGE
================================================================================

from slope_stability_newmark import (
    SlopeGeometry, SoilProfile, SeismicParameters,
    SlopeStabilityAnalyzer, D73FeedbackHook
)

# Define slope geometry
slope = SlopeGeometry(
    angle_degrees=30.0,
    height=15.0
)

# Define soil layers
soils = [
    SoilProfile(
        depth_top=0.0, depth_bottom=10.0,
        unit_weight=19.0, cohesion=25.0, friction_angle=32.0,
        spt_n_value=15, liquefaction_potential=False
    )
]

# Define seismic input
seismic = SeismicParameters(pga=0.32, magnitude=7.0)

# Run analysis
analyzer = SlopeStabilityAnalyzer(slope, soils, seismic)
result = analyzer.analyze()

# Print results
print(f"Permanent deformation: {result.permanent_deformation_cm:.2f} cm")
print(f"Factor of Safety: {result.factor_of_safety:.3f}")
print(f"Risk Level: {result.risk_level.value}")
print(f"Slip Probability: {result.slip_probability:.1%}")

# Check for intervention needs (D7.3)
hook = D73FeedbackHook(fos_threshold=1.3)
recommendations = hook.evaluate_intervention_need(result)
if recommendations['intervention_needed']:
    print("Actions needed:")
    for action in recommendations['suggested_actions']:
        print(f"  - {action}")
