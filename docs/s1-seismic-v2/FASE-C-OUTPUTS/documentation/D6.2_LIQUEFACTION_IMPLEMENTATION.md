## Algorithm Implementation

### 1. Tokimatsu & Yoshida (1983) Liquefaction Index

**Liquefaction Index (LI)** is the sum of layer-by-layer contributions:

```
LI = Σ(1 − FS_i)    [for each saturated 1m layer i]
```

Where each layer's **Factor of Safety (FS)** is:

```
FS_i = CRR / (CSR × MSF × rd)
```

### 2. Cyclic Resistance Ratio (CRR)

CRR is derived from SPT N-value with corrections for overburden and fines:

```
CRR(M=7.5) = f(N1_60, fines%)

where:
  N1_60 = N × CN × CE × CB
  CN = Overburden correction = (100 / σ'_v0)^0.5  [capped at 1.7]
  CE = Fines correction       [1.0 for clean sand, 0.9 for >35% fines]
  CB = Hammer energy ratio    = 1.2 [Japanese SPT vs. ASTM 60%]
```

**CRR Empirical Correlation** (Tokimatsu & Yoshida, 1983):
- N1_60 ≤ 3: CRR = 0.02 (very loose)
- 3 < N1_60 ≤ 30: CRR = (N1_60 + 15) / 1000 (linear)
- 30 < N1_60 ≤ 50: CRR = 0.02 + (N1_60 − 30) / 400
- N1_60 > 50: CRR = 0.06 (very dense)

### 3. Cyclic Stress Ratio (CSR)

CSR quantifies seismic shear stress normalized by effective stress:

```
CSR = τ_av / σ_v0 = 0.65 × (a_max/g) × (σ_v0/σ_v0') × rd

where:
  a_max = peak ground acceleration (m/s²)
  g = gravitational acceleration (9.81 m/s²)
  σ_v0 = total vertical stress (kPa)
  σ_v0' = effective vertical stress (kPa)
  rd = depth reduction factor
```

**Coefficients** (Seed & Idriss, 1971):
- Static shear stress coefficient: **0.65**

### 4. Magnitude Scaling Factor (MSF)

Idriss (2004, 2008) magnitude scaling normalizes CRR to reference M=7.5:

```
MSF = (7.5 / M)^2.56

Behavior:
  M = 6.5 → MSF = 1.42 (lower magnitude requires higher CRR)
  M = 7.5 → MSF = 1.00 (reference magnitude)
  M = 8.5 → MSF = 0.70 (higher magnitude is more damaging)
```

### 5. Depth Reduction Factor (rd)

Empirical reduction accounting for stress confinement effects:

```
For 0 ≤ z ≤ 9.15m:
  rd = 1.0 − 0.00765 × z

For 9.15 < z ≤ 20m:
  rd = 1.174 − 0.0267 × z

For z > 20m:
  rd ≈ 0.6 (extrapolated, warning issued)
```

**References**: Idriss & Boulanger (2008)

### 6. Liquefaction Index Contribution

Each 1m layer contributes to total LI:

```
LI_i = max(0, 1 − FS_i)

LI ∈ [0.0, 1.0] for each layer
  LI = 0.0 → FS ≥ 1.0 (safe)
  LI = 0.5 → FS = 0.5 (liquefied)
  LI = 1.0 → FS → 0 (complete liquefaction)
```

### 7. Risk Classification

**Site-Level Risk** (Tokimatsu & Yoshida, 1983):

| LI Range | Risk Level |
|----------|-----------|
| LI < 5 | Very Low |
| 5 ≤ LI < 15 | Low |
| 15 ≤ LI < 30 | Moderate |
| 30 ≤ LI < 50 | High |
| LI ≥ 50 | Very High |

**Layer-Level Risk** (FS-based):

| FS Range | Risk Level |
|----------|-----------|
| FS ≥ 1.2 | Very Low |
| 1.0 ≤ FS < 1.2 | Low |
| 0.75 ≤ FS < 1.0 | Moderate |
| 0.50 ≤ FS < 0.75 | High |
| FS < 0.50 | Very High |

## Code Architecture

### Core Classes

#### `LiquefactionAnalyzer`
Main analysis engine orchestrating all calculations.

**Methods**:
- `__init__(site_id, verbose)` - Initialize analyzer
- `analyze_layer(layer, site_conditions)` → `LiquefactionResult`
- `analyze_site(layers, site_conditions, water_table_depth)` → `SiteAnalysisResult`
- `export_csv(result, filename)` - Export layer-by-layer CSV

#### `CorrectionFactors` (Static)
SPT correction calculations.

**Methods**:
- `overburden_correction(sigma_v0_prime)` → CN
- `fines_correction(fines_content)` → CE
- `depth_reduction_factor(depth_mid)` → rd

#### `MagnitudeScaling` (Static)
Earthquake magnitude effects on liquefaction resistance.

**Methods**:
- `idriss_2004_msf(magnitude, n_corrected)` → MSF
- `idriss_boulanger_2008_msf(magnitude)` → MSF

#### `CyclicStressRatio` (Static)
Dynamic shear stress calculations.

**Methods**:
- `calculate_csr(peak_accel_g, sigma_v0, sigma_v0_prime, rd)` → CSR

#### `CyclicResistanceRatio` (Static)
SPT-based resistance from cyclic loading.

**Methods**:
- `calculate_crr_from_spt(n_value, sigma_v0_prime, fines_content)` → CRR

#### `FactorOfSafety` (Static)
Safety factor and LI contribution.

**Methods**:
- `calculate_fs(crr, csr, msf, rd)` → FS
- `calculate_li_contribution(fs)` → LI

#### `RiskAssessment` (Static)
Risk classification.

**Methods**:
- `classify_layer_risk(fs, li)` → RiskLevel
- `classify_site_risk(total_li)` → RiskLevel

#### `D73FeedbackInterface` (Static)
Integration hook for feedback module.

**Methods**:
- `prepare_feedback_package(result, analyst_notes, next_steps)` → Dict
- `export_json(result, filename, analyst_notes, next_steps)` → JSON file

### Data Classes

#### `LayerData`
Single 1m soil layer properties with validation.

**Fields**:
- `depth_mid: float` - Depth to layer midpoint (m)
- `n_value: int` - Uncorrected SPT N (blows/30cm)
- `fines_content: float` - Fines % (silt + clay)
- `water_table_depth: float` - Depth to water table (m)
- `unit_weight: float` - Total unit weight (kN/m³)
- `sigma_v0_prime: float` - Effective vertical stress (kPa)

#### `SiteConditions`
Earthquake and site parameters with validation.

**Fields**:
- `magnitude: float` - Earthquake magnitude (Mw 4.0-9.0)
- `peak_accel_g: float` - Peak acceleration (fraction of g)
- `depth_water_table: float` - Depth to water table (m)
- `vs30: float` - Shear wave velocity 0-30m (m/s)

#### `LiquefactionResult`
Single-layer analysis output.

**Fields**:
- `depth_mid, n_value, n_corrected`
- `crr, csr, msf, rd` - Calculation intermediate values
- `fs, li_contribution` - Factor of safety and LI
- `soil_type, risk_level` - Classifications
- `notes: str` - Analyst notes

#### `SiteAnalysisResult`
Complete site analysis with all layers.

**Fields**:
- `site_id, magnitude, peak_accel_g`
- `total_li, risk_level, liquefiable_depth`
- `num_high_risk_layers`
- `layers: List[LiquefactionResult]` - Per-layer results
- `warnings: List[str]` - Quality flags
- `debug_log: Dict` - Statistics for QA

## Usage Examples

### Basic Single-Layer Analysis

```python
from liquefaction_d62 import LiquefactionAnalyzer, LayerData, SiteConditions

# Create analyzer
analyzer = LiquefactionAnalyzer(site_id="PROJECT-001")

# Define soil layer
layer = LayerData(
    depth_mid=5.0,
    n_value=15,
    fines_content=20.0,
    water_table_depth=2.0,
    unit_weight=19.5,
    sigma_v0_prime=85.0
)

# Define earthquake scenario
site_conditions = SiteConditions(
    magnitude=7.5,
    peak_accel_g=0.35,
    depth_water_table=2.0,
    vs30=180.0
)

# Analyze
result = analyzer.analyze_site([layer], site_conditions)

# Review results
print(f"LI = {result.total_li:.3f}")
print(f"Risk Level = {result.risk_level.value}")
print(result.summary())
```

### Multi-Layer Profile Analysis

```python
# Define multiple layers
layers = [
    LayerData(depth_mid=1.0, n_value=5, fines_content=15.0, ...),
    LayerData(depth_mid=2.5, n_value=12, fines_content=18.0, ...),
    LayerData(depth_mid=4.0, n_value=20, fines_content=20.0, ...),
    LayerData(depth_mid=5.5, n_value=28, fines_content=10.0, ...),
    # ... more layers
]

# Analyze entire profile
result = analyzer.analyze_site(layers, site_conditions)

# Export for review
analyzer.export_csv(result, "liquefaction_analysis.csv")
```

## Support & Maintenance

### Troubleshooting

**High FS values (> 2.0) for loose sand**:
- Check unit weight validity
- Verify effective stress calculation
- Confirm water table depth

**Low LI but high layer risk**:
- Normal for single or few layers
- Site risk based on cumulative LI
- Layer risk reflects individual safety

**MSF confusion**:
- Higher magnitude (M > 7.5) → lower MSF → more liquefaction
- Lower magnitude (M < 7.5) → higher MSF → less liquefaction
- Reference: M = 7.5 → MSF = 1.0
