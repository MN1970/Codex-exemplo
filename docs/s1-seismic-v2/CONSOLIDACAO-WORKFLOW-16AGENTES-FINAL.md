##### 🟡 **D7.3 — Geometry-Talude Interaction** (778 linhas)
**Conteúdo**:
- Feedback loop Newmark (D6.3) → Geometry (D7)
- Critério disparo: deformation > 0.5 m
- 4 estratégias sequenciais: redução β → aumento Rv → combinada → escavação
- Algoritmo iterativo (~200 linhas pseudocódigo)
- Critério convergência (primária: deformation ≤ limite; secundária: |def_n − def_{n-1}| < 0.05m)
- **Exemplo prático Jericó Km 45+800**:
  - Entrada: gnaisse β=35°, H=15m, Rv=80m, a_max=0.15g, def=0.68m
  - 3 iterações: β→33°→29°, Rv→96m→125m, berma=3m
  - Resultado: def=0.48m ✓, FS 1.42→1.68, custo R$ 15.6k
- Stack: Python/C++, PostgreSQL+PostGIS, Airflow
- Extensões futuras: drenagem, reforço geotêxtil, multicritério
