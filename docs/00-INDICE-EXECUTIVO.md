## SUMÁRIO EXECUTIVO

Este compêndio consolida as **cinco principais normas brasileiras** (DNIT, CONTRAN, ANTT) aplicáveis a dispositivos viários de segurança e contenção. Inclui especificações técnicas mínimas, critérios de enquadramento, tabelas comparativas e cronogramas de manutenção, com enfoque em:

1. **Defensas metálicas** (guard-rails)
2. **Barreiras rígidas** (tipo New Jersey)
3. **Atenuadores de impacto** (crash cushions)
4. **Demarcação horizontal e sinalização** (linhas, cores, refletância)

## PRINCIPAIS NORMAS RESUMIDAS EM UMA PÁGINA

### 1. **DNIT IPR-718** — Manual de Projeto de Interseções (2ª ed. 2005)

| Atributo | Detalhe |
|----------|---------|
| **Aplicação** | Classificação e seleção de interconexões (em nível e em desnível) |
| **Capítulos-chave** | Cap. 6 (Classificação); Cap. 7 (Desnível: Trombeta, Diamante, Trevo, Direcional); Cap. 8 (Nível: T/Y, Rótula) |
| **Requisitos** | VP (40–120 km/h); raios mínimos; comprimentos de aceleração/desaceleração; área de ocupação |
| **Status** | Obrigatório em projetos federais e estaduais |

---

### 2. **DNIT Manual de Projeto e Práticas Operacionais para Segurança nas Rodovias**

| Dispositivo | Altura | Espaçamento | Material | Vida Útil |
|-------------|--------|------------|----------|-----------|
| **Defensa Metálica** | 0,70 m | e = 2–4 m | Aço galv. | 20–25 anos |
| **Barreira Rígida (NJ)** | 0,81–1,07 m | Juntas 6 m máx. | Concreto f'c≥30 | 30–40 anos |
| **Atenuador de Impacto** | 0,80–1,20 m | Localizado | Módulos chevron | 3–5 anos |

---

### 3. **CONTRAN Manual de Sinalização** (Vol. I–VII, 2014)

| Aspecto | Requisito |
|--------|-----------|
| **Vol. IV (Demarcação)** | Amarelo = eixo/sentidos opostos; Branco = bordo/mesmo sentido |
| **Vol. VI (Complementares)** | Tachas, balizadores refletivos; Refletância ≥ 50 cd/lux/m² |
| **Vol. VII (Provisória)** | Cones e balizadores móveis em manutenção |

---

### 4. **DNIT 100/2018-ES** — Sinalização Horizontal

| Parâmetro | Especificação |
|-----------|-------------|
| **Largura de linha** | 10 cm ±1 cm |
| **Espessura de película seca** | 0,50–0,65 mm |
| **Vidro refletor** | Type I ou II (Bead refletivo) |
| **Cura antes de tráfego** | 3–7 dias (clima tropical) |
| **Refletância mínima** | Amarelo: ≥ 50 cd/lux/m²; Branco: ≥ 100 cd/lux/m² |

---

### 5. **ANTT Manual de Fiscalização de Rodovias Federais Concedidas**

| Item | Frequência | Prazo de Reparação |
|------|-----------|-------------------|
| **Inspeção de defensas (4.3)** | Trimestral (chuva) / Semestral (seco) | Reparação em 30 dias |
| **Inspeção de barreiras (4.2)** | Semestral | Reparação em 30–60 dias |
| **Atenuador pós-impacto** | Pós-acidente (imediato) | Substituição em 7 dias |
| **Anti-ofuscante (4.4)** | Semestral | Limpeza em 30 dias |

## FLUXO DE DECISÃO — 5 PASSOS

```
┌─────────────────────────┐
│ 1. VELOCIDADE DE PROJETO (VP)
│    ├─ ≤ 60 km/h   → Defensa simples (e=3m)
│    ├─ 60-80 km/h  → Defensa dupla
│    ├─ 80-100 km/h → Barreira rígida
│    └─ > 100 km/h  → Barreira rígida + Atenuador
└─────────────────────────┘
              ↓
┌─────────────────────────┐
│ 2. ÁREA LIVRE DISPONÍVEL
│    ├─ ≥ 7,5 m    → Defensa(s) OK
│    ├─ 4,5-7,5 m  → Defensa ou Barreira
│    └─ < 4,5 m    → Barreira rígida (obrigatória)
└─────────────────────────┘
              ↓
┌─────────────────────────┐
│ 3. TIPO DE OBSTÁCULO
│    ├─ Talude de corte → Defensa metálica
│    ├─ Canteiro central → Barreira rígida
│    ├─ Pilar OAE      → Atenuador + Barreira
│    └─ Bifurcação     → Atenuador de impacto
└─────────────────────────┘
              ↓
┌─────────────────────────┐
│ 4. TIPO DE INTERSEÇÃO (IPR-718)
│    ├─ Nível: T/Y, Rótula
│    ├─ Desnível: Diamante, Trevo, Trombeta
│    └─ Critério: Sinalização semafórica necessária?
└─────────────────────────┘
              ↓
┌─────────────────────────┐
│ 5. REGIME DE MANUTENÇÃO
│    ├─ Federalizada → Semestral (DNIT)
│    ├─ Concedida    → Trimestral (ANTT)
│    └─ Municipal    → Anual (orçamento disponível)
└─────────────────────────┘
              ↓
        DISPOSITIVO
         SELECIONADO
```

## COMO USAR ESTE COMPÊNDIO

### Para **Projetos Novos**:
1. Consulte **Tabelas Comparativas** (Seção 3) — árvore de decisão
2. Selecione dispositivo apropriado
3. Verifique **Fichas Técnicas** para especificações exatas
4. Aplique **DNIT 100/2018** para demarcação horizontal
5. Defina cronograma via **Tabelas** (Seção 5 — ANTT)

### Para **Inspeção/Auditoria**:
1. Use **Checklist de Conformidade** (Tabelas, Seção 7)
2. Valide cronograma contra **ANTT** (Tabelas, Seção 5)
3. Verifique especificações vs. **Normas** (Arquivo 1)
4. Registre achados

### Para **Treinamento Técnico**:
1. Distribua **Fichas Técnicas** (Arquivo 2) — leitura rápida
2. Apresente **Árvore de Decisão** (Tabelas, Seção 3)
3. Reforce com **Checklist** (Tabelas, Seção 7)
4. Teste compreensão via cenários das **Tabelas Comparativas** (Seção 1)

### Para **Licitação/Contrato**:
1. Extraia requisitos de **Normas** (Arquivo 1)
2. Insira referências normativas em **Termos de Referência**
3. Defina prazos de manutenção conforme **ANTT** (Tabelas, Seção 5)
4. Inclua **Checklist** (Tabelas, Seção 7) nos critérios de aceitação
