## File Inventory

### Execution Scripts (2)

#### 1. `scripts/eval_embeddings_ab.py` (630 lines)
**Purpose:** Full A/B test with real embedding models  
**Language:** Python 3.10+  
**Dependencies:** torch, transformers, numpy, scipy  

**Features:**
- Loads both embedding models from Hugging Face
- Computes 4 metrics: Recall@5, MRR, NDCG@5, latency
- Implements cosine similarity ranking
- Mock chunk generation for controlled evaluation
- Caching for efficiency
- Detailed progress logging

**Usage:**
```bash
# GPU (recommended)
python scripts/eval_embeddings_ab.py --device cuda

# CPU
python scripts/eval_embeddings_ab.py --device cpu

# Verbose
python scripts/eval_embeddings_ab.py --verbose
```

**Output:**
- JSON: `rag_evals/eval_embeddings_ab_results.json` (4-5MB)
- Console: summary table + recommendations

**Runtime:** 30 min (CPU) / 5 min (GPU)

### Documentation (3)

#### 1. `docs/RAG-EMBEDDING-AB-TEST.md` (400 lines, 15KB)
**Purpose:** Complete technical specification  
**Audience:** Engineers, data scientists  
**Level:** Advanced

**Contents:**
- Objective & constraints
- Methodology (BM25 + embedding + reranking)
- Metric definitions with formulas:
  - Recall@5
  - MRR (Mean Reciprocal Rank)
  - NDCG@5 (Normalized Discounted Cumulative Gain)
  - Latency (ms)
- Decision criteria (>10% improvement = winner)
- Execution instructions
- Result interpretation
- Sensitivity analysis (by difficulty, segment)
- Next steps per outcome
- Troubleshooting guide
- Roadmap (6/9/12 months)

**Key Equations:**
```
Recall@5 = (n_qa_with_golden_in_top5) / n_total_qa

MRR = avg([1/rank_i if rank_i <= 5 else 0 for all QAs])

NDCG@5 = DCG@5 / IDCG
  where DCG@5 = Σ(i=1 to 5) [1/log₂(i+1)] × rel(i)

confidence = min(0.95, 0.50 + improvement_recall / 100)
```
