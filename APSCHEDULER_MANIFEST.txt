DEPENDENCIES
================================================================================

Required:
  - APScheduler 3.10+
  - pytz (timezone handling)
  - supabase-py (Supabase client)
  - python-dotenv (env file loading)

Install:

  # or manually:
  pip install APScheduler pytz supabase-py python-dotenv requests
