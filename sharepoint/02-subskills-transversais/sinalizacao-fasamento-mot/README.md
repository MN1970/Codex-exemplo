# Mirror SharePoint — sinalizacao-fasamento-mot (MOT)

Este diretório é o **mirror versionado** do `SKILL.md` do orquestrador
MOT (`.claude/skills/mot-orquestrador/SKILL.md`), a ser sincronizado
manualmente para o SharePoint da Manta em:

`04_IA/Manta-Maestro/02-subskills-transversais/sinalizacao-fasamento-mot/`

Esta é a **primeira sub-skill transversal** deste repositório. Difere
das verticais S6-S10 já existentes em `01-agentes-fundamentais/`: não é
um segmento/agente novo, e sim uma **extensão de capacidade** dos
agentes já operacionais **S1 (Rodovias)** e **S2 (OAE)**, cobrindo o
faseamento de tráfego em trevos e interseções durante obra.

A pasta espelho no SharePoint deve conter, no mínimo:

- `README.md` — este arquivo (ou sua versão sincronizada).
- `SKILL.md` — cópia do orquestrador (`mot-orquestrador`).

A sincronização é **manual**: alterações feitas aqui no repositório
`Codex-exemplo` devem ser replicadas para o SharePoint pelo responsável
de deploy, seguindo o mesmo checklist de gate humano (aprovação MN)
usado para as demais publicações do Manta Maestro.
