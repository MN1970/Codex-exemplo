OVERVIEW
================================================================================

Complete implementation of R10 (Purga de Agent_Memory) from CLAUDE.md v5.0 with 
enhanced 3-tier cache lifecycle management, automatic cleanup policies, graceful 
LRU eviction, and R9 feedback loop integration.

3-Tier Architecture:
  • HOT:  In-process memory, 30 min TTL (last 100 completions)
  • WARM: Supabase agent_memory, 480 min TTL (with user feedback)
  • COLD: agent_memory_archive, 90 days retention (GDPR compliant)

Key Features:
  ✓ Automatic tier transitions (HOT→WARM→COLD→DELETE)
  ✓ Graceful LRU eviction when quota > 80%
  ✓ Integration with R9 embedding retraining loop
  ✓ Real-time quota monitoring & anomaly detection
  ✓ Slack alerting (quota violations + anomalies)
  ✓ Grafana metrics export
  ✓ Audit trail (append-only tier_log)

ARCHITECTURE SUMMARY
================================================================================

Tier Transitions:

  HOT (in-process)
    └─ (30 min inactivity) ──→ WARM (Supabase)
                                 └─ (480 min + rating < 2) ──→ COLD (Archive)
                                                                  └─ (90 days) ──→ DELETE

LRU Eviction:
  When quota > 80%:
    └─ Delete oldest WARM/HOT entries with:
       • access_count < 2, OR
       • user_rating < 2
    Until quota < 60%

R9 Integration:
  High-rating entries (rating ≥ 4, feedback_score ≥ 0.8):
    └─ Extracted by cleanup script
    └─ Sent to R9 retraining job
    └─ Embedding model updated
    └─ Next tiering cycle uses new embeddings
