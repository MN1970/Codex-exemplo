## Formato de Preenchimento

**Quando adicionar uma linha:**

1. **Desvios de Prazo:** Se uma tarefa vai atrasar > 30 min, registre assim:
   ```
   | 2026-07-26 | 1.1 (Supabase) | Terça 26 jul 09:00 | Terça 26 jul 12:00 | Dados SNIS maiores que o esperado | SIM (atrasa 2.2) | ⏳ Em andamento |
   ```

2. **Bloqueadores:** Se algo bloqueia o trabalho:
   ```
   | 2026-07-26 | 1.1 | API Supabase fora do ar | Contato especialista BD + MN | especialista-bd | 2026-07-26 15:00 |
   ```

3. **Lições:** Ao final de cada tarefa:
