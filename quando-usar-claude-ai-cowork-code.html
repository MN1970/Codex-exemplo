Quando Usar: Claude AI vs Cowork vs Claude Code

Guia de decisão para escolher a ferramenta certa para orquestração de múltiplos agentes Manta

Visão Geral das 3 Plataformas

🧠

Claude AI (web)

Interface Web

O quê: Interface conversacional oficial do Claude em claude.ai

Foco: Interação humana com um agente (1:1)

Bom para: Perguntas pontuais, brainstorm colaborativo, revisão de documentos

Max agentes paralelos: 1 (você conversa com Claude)

🤝

Claude Cowork

Colaborativo

O quê: Espaço compartilhado para equipes colaborarem com Claude

Foco: Múltiplos usuários, um agente central coordenador

Bom para: Revisão em tempo real, aprovações, decisões em grupo

Max agentes paralelos: 1 coordenador + múltiplos usuários

⚙️

Claude Code

Orquestração

O quê: CLI + IDE extensions + servidor remoto para automação

Foco: Workflows automatizados, fan-out paralelo, integração git

Bom para: Múltiplos agentes em paralelo, pipelines, integração CI/CD

Max agentes paralelos: 16 simultâneos (min(16, cores-2))

Matriz de Decisão

Critério Claude AI Cowork Claude Code
Usuários simultâneos 1 (você) N (equipe) 1 (automation)
Agentes paralelos 1 1 principal 16
Workflows Conversação Conversação em grupo Determinísticos (Code)
Integração git ❌ Nenhuma ⚠️ Limitada ✅ Full (push/PR/CI)
RAG / Knowledge ✅ Browsing ✅ Docs compartilhados ✅ Supabase pgvector
Tempo de resposta Instant (chat) Instant (chat) Latência = N × (tempo por agente)
Custo Claude Pro ou API Claude Pro ou Cowork license API usage + infra (remote env)
Escalabilidade Baixa (conversação) Média (grupo) Alta (auto-scaling)

Cenários de Uso por Ferramenta

🧠 Claude AI — Quando Usar

Cenário 1: Análise rápida de edital Um sócio recebe um edital rodoviário e quer um parecer técnico em 5 minutos. Ele abre claude.ai, cola o PDF, conversa diretamente com Claude. Resposta rápida, personalizada pela conversa.
Cenário 2: Brainstorm de proposta Equipe discute abordagem técnica para concessão portuária. Usam Claude AI como "colega" — fazem perguntas, refinam ideias, Claude propõe estruturas. Interação humana é central.
Cenário 3: Revisão de documento Draft de parecer técnico pronto. Usuário cola em claude.ai, pede para revisar gramática, lógica, conformidade com padrões Manta. Claude faz sugestões inline.
Cenário 4: Pesquisa web rápida "Qual é a taxa SELIC hoje?" Claude busca (web browsing), responde com contexto. Sem necessidade de automação.
  • Use quando: **interação humana é o ponto central**
  • Use quando: precisa de feedback/aprovação antes da próxima etapa
  • Use quando: decisão é exploratória (não determinística)
  • ⚠️ NÃO use para orquestração de múltiplos agentes
  • ⚠️ NÃO use para workflows repetitivos/automáticos

🤝 Cowork — Quando Usar

Cenário 1: Revisão em tempo real por múltiplos stakeholders Proposta comercial pronta. 4 pessoas (sócio, gerente, técnico, comercial) abrem Cowork compartilhado, discutem alterações simultaneamente em tempo real. Claude coordena sugestões.
Cenário 2: Aprovação com trail de decisão Análise de claim está pronta. Sócio abre Cowork, revisa, deixa comentários. Subordinado vê comentários, faz ajustes, novo review. Histórico completo fica no Cowork.
Cenário 3: Workshop colaborativo** Reunião estratégica de 10 pessoas sobre posicionamento em licitação. Usam Cowork para brainstorm facilitado: alguém propõe estratégia, Claude ajuda estruturar, equipe vota/discute.
Cenário 4: Onboarding de novo projeto Novo cliente. Time de 6 pessoas entra no Cowork dedicado do projeto, vê contexto (edital, briefing), Claude pergunta clarificações, time responde em paralelo.
  • Use quando: **múltiplos usuários precisam colaborar**
  • Use quando: aprovações/reviews são síncronos
  • Use quando: trail de decisão é importante
  • Use quando: comunicação é não-determinística (discussão)
  • ⚠️ NÃO use como substituto de Claude Code para automação
  • ⚠️ NÃO escalável além de ~10 pessoas simultâneas

⚙️ Claude Code — Quando Usar

Cenário 1: Fan-out de 16 agentes em paralelo Proposta expressa de concessão rodoviária. Claude Code executa: A7 (mercado) + S1 (técnico) + A5 (orçamento) + A4 (cronograma) + A8 (deck) + 11 agentes mais em paralelo. Wall-clock 7 minutos.
Cenário 2: Pipeline de indexação RAG** Novo projeto entrou no SharePoint. Claude Code dispara: A2 (extrai quantidades) → A5 (calcula custos) → indexa em Supabase pgvector. Tudo automático, sem humano.
Cenário 3: Rotina noturna de análise** Toda noite, Claude Code: scan de licitações novas (web) → classifica por segmento (S1-S11) → estima viabilidade (A6) → armazena em RAG → notifica equipe. Sem intervenção humana.
Cenário 4: Integração git + CI/CD** Desenvolvedor faz push. Claude Code: roda testes automaticamente, revisa código, abre PR com sugestões de melhoria, atualiza docs. Tudo integrado ao GitHub.
Cenário 5: Monitoria de claims em tempo real** Workflow de 2h: A1 (reequilíbrio) → A3 (contratual) → A1-reavaliação (votação adversarial 3x) → se aprovado, gera documentação (A8). Determinístico, sem decisão humana.
  • Use quando: **automação é o objetivo**
  • Use quando: múltiplos agentes em paralelo são necessários
  • Use quando: workflow é determinístico (if-then, não exploratório)
  • Use quando: escala é importante (1000s de operações)
  • Use quando: integração git/CI/CD é necessária
  • ✅ **USE PARA MANTA MAESTRO — orquestração de 20 agentes**

Árvore de Decisão Rápida

Comece aqui:

❓ O usuário está em frente a uma tela interagindo agora?

  • ✅ SIM, conversando sozinho → Claude AI
  • ✅ SIM, em reunião com 2–10 pessoas → Cowork
  • ❌ NÃO, é automação agendada/background → continuar

❓ Precisa executar 1 agente ou múltiplos agentes?

  • 1 agente → Claude AI ou Cowork (conforme acima)
  • 2–16 agentes em paralelo → Claude Code
  • >16 agentes → **Claude Code em lotes** (16+16+...)

❓ O workflow é determinístico ou exploratório?

  • Determinístico (A→B→C sempre) → Claude Code
  • Exploratório (precisa de feedback/iteração) → Claude AI ou Cowork

❓ Vai integrar com git/CI/CD ou agendar no cron?

  • SIM → Claude Code (obrigatório)
  • NÃO → Claude AI ou Cowork

Exemplo Real: Proposta Rodoviária Expressa

Contexto: Sócio recebe edital rodoviário. Prazo: amanhã às 10h. Hoje 18h. 16 horas para entregar proposta.

❌ Errado: Claude AI

Sócio abre claude.ai, copia edital, começa conversa. A5 (orçamento) leva 2h numa conversa interativa. S1 (técnico) leva 3h. A8 (deck) leva 4h. Total: 9h + breaks = 12h. Cansaço mental. Risco de erro.

⚠️ Parcialmente certo: Cowork

Equipe de 4 abre Cowork. Discutem abordagem, distribuem tarefas. Claude "facilita". Mas cada pessoa ainda executa sequencialmente (A7 → A5 → S1 → A8). 10h+ de clock. Melhor que solo, mas ainda serial.

✅ Certo: Claude Code

Sócio dispara workflow Claude Code. Maestro lança 16 agentes em paralelo: A7 + S1 + A9 + A5 + A2 + A4 + A6 + A1 + A3 + A10 + F-advisory + A8 + ... Wall-clock: 7 min análise + 5 min síntese. Total: ~30 min. Sócio revisa, faz pequenos ajustes, submit 22h.

Implementação Recomendada para Manta

3 Modos de Operação

Modo 1: Interativo

Sócio usa Claude AI para perguntas pontuais, brainstorm. Resposta em minutos.

Modo 2: Colaborativo

Equipe usa Cowork para revisar/aprovar drafts. Discussão síncrona, trail auditável.

Modo 3: Automático

Claude Code executa workflows paralelos. Resposta em horas. Sem humano envolvido.

Setup Técnico por Plataforma

Claude AI

  • Abra claude.ai (web ou mobile app)
  • Login com email manta (mneves@mantaassociados.com)
  • Comece conversa — Claude já tem web browsing ativo
  • Sem setup necessário

Cowork

  • Peça ao admin para criar espaço Cowork para projeto
  • Convide stakeholders (sócio, gerentes, técnicos)
  • Comece discussão — Claude facilita automaticamente
  • Histórico completo fica no Cowork (auditável)

Claude Code

  • Instale CLI: npm install -g @anthropic-ai/claude-code
  • Ou use IDE extension (VS Code, JetBrains)
  • Configure ~/.claude/settings.json com CLAUDE.md do projeto
  • Defina remote environment (VPS + orquestração Maestro)
  • Crie workflows em scripts JavaScript (Workflow tool)
  • Execute: claude code path/to/workflow.js
