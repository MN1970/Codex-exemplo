QUICK START GUIDE
================================================================================

1. INSTALL DEPENDENCIES
   $ pip install requests

2. SETUP ENVIRONMENT
   $ bash QUICK-START.sh --setup
   (or manually set 3 required + 4 optional env vars)

3. RUN TESTS
   $ bash QUICK-START.sh --test

4. VALIDATE SETUP
   $ bash QUICK-START.sh --run   (dry-run, no SP write)

5. FULL TEST (with credentials)
   $ bash QUICK-START.sh --run-full

6. INTEGRATE WITH CLAUDE CODE
   - Copy .claude/settings-healthcheck.example.json to .claude/settings.json
   - Customize SessionStart hook
   - Restart Claude Code session
   - Check .healthcheck.json after SessionStart
